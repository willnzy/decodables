## 🚨 风险和注意事项

### 风险 1: 文档链接失效

**影响**: 其他文档中的链接可能指向旧路径

**缓解措施**:
- 执行前用 `grep` 搜索所有文档链接
- 批量更新链接
- 验证所有链接有效性

### 风险 2: 合并后文档过大

**影响**: 单个文档超过 1,500 行，阅读体验下降

**缓解措施**:
- 添加详细目录 (TOC)
- 使用折叠章节 (Markdown details)
- 分章节编号，方便引用

### 风险 3: 历史信息丢失

**影响**: 合并时可能遗漏重要历史记录

**缓解措施**:
- 合并前完整阅读两个文档
- 提取所有独特信息
- 保留 Git 历史 (不删除旧 commits)
