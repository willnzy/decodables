## 促销类型

| 类型 | 说明 | 适用范围 |
|------|------|----------|
| 限时折扣 | 指定时间段折扣 | 订阅/积分 |
| 首购优惠 | 首次购买折扣 | 订阅 |
| 节日活动 | 节日促销 | 全部 |
| 用户召回 | 流失用户优惠 | 订阅 |

## 折扣方式

| 方式 | 示例 | 说明 |
|------|------|------|
| 百分比折扣 | 20% off | 按原价百分比 |
| 固定金额减免 | $5 off | 固定金额 |
| 固定价格 | $4.99 | 直接设定 |
| 试用期延长 | +7 days | 延长试用 |

---

## 促销规则

优先级（不叠加）：

```
1. 用户专属优惠
2. 首购优惠
3. 限时促销
4. 默认价格
```

限制项：

- 每用户使用次数
- 总使用次数
- 适用 Tier
- 新用户限定

---

## 倒计时设计

```
> 7 天: 显示日期
≤ 7 天: 显示剩余天数
≤ 24 小时: 显示时分秒
已结束: 显示已结束
```

展示位置：

- Pricing 页面
- Dashboard 卡片
- 升级弹窗

---

## 促销配置（摘要）

核心表：

- `promotions`

促销码规则：

- 4-20 字符
- 大写字母 + 数字
- 不含特殊字符
