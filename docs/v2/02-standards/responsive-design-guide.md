## 背景

- 问题或机会: 端内页面布局不一致，移动端体验需要统一标准
- 目标与非目标: 目标是统一响应式策略与交互规范；非目标是替代具体页面设计

## 设计约束（强制）

- 禁止照搬旧文档结构或原文段落
- 必须与覆盖矩阵保持一致

## 结论/规范/方案

- Mobile-first
- 触摸目标 ≥ 44px
- Safe area 适配
- `md` = 768px 为移动/桌面分界

## 详细说明

- 断点体系与适配策略: 默认移动端样式，`md` 以上增强布局
- 交互与触摸规范: 触控区域 ≥ 44px，提供按压反馈与安全区适配
