## 背景

- 问题或机会: 导航与 Tab 行为不一致，影响可用性与可预测性
- 目标与非目标: 目标是统一导航层级与交互规则；非目标是替代具体页面结构设计

## 结论/规范/方案

- 三层导航：主导航 / 子级 Tab / 操作按钮
- Tab 规范：语义色映射 / 锁定与禁用状态
