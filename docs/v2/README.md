# 文档中心 v2

> 统一文档框架（前后端一致），覆盖研发、产品、设计、运营、支持与合规。

---

## 目录结构

```
docs/v2/
├── 00-governance/        # 文档规范与治理
├── 01-architecture/      # 架构与ADR
├── 02-standards/         # 开发规范与工程标准
├── 03-business/          # 业务规则与数据契约
├── 04-features/          # 功能设计与方案
├── 05-api/               # API 设计与参考
├── 06-operations/        # 运维、监控、SRE
├── 07-plans/             # 计划、里程碑、路线图
├── 08-reports/           # 审计、复盘、执行结果
├── 09-reference/         # 术语表、字典、FAQ
├── 10-product/           # PRD、体验与需求文档
├── 11-go-to-market/      # 市场、增长、销售资料
├── 12-support/           # 支持与客服知识库
├── 13-legal-compliance/  # 合规、隐私、条款
└── 99-archive/           # 历史归档
```

---

## 使用原则

- 新文档一律放入 `docs/v2/`
- 旧文档保留不删，直到多次检查完成
- 共享文档在前后端保持相同路径与内容
