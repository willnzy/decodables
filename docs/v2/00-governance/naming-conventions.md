# 命名与路径规范

## 文件命名

- 统一使用 `kebab-case.md`
- 仅使用 ASCII 字符
- 避免空格、中文标点、括号

示例：

- `backend-architecture.md`
- `tier-naming-system.md`
- `audit-report-20260204.md`

## 版本命名

- 文件名可用后缀标识版本：`feature-flag-design-v2.md`
- 多版本并行时使用目录隔离：`v2/`、`v3/`

## 临时与归档

- 临时文档：`YYYYMMDD-description.md`
- 归档文档统一迁入 `99-archive/`
