## 一、审计范围总览

### 1.1 审计三层架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    Layer 1: 数据库层                              │
│  ├── 表结构设计 (Schema)                                         │
│  ├── 约束与索引 (Constraints/Indexes)                            │
│  ├── RPC 函数 (原子操作)                                          │
│  └── RLS 策略 (行级安全)                                          │
├─────────────────────────────────────────────────────────────────┤
│                    Layer 2: 后端逻辑层                            │
│  ├── Domain Services (业务逻辑)                                   │
│  ├── Application Handlers (用例编排)                              │
│  ├── API Routes (接口定义)                                        │
│  └── Webhook Handlers (外部事件处理)                              │
├─────────────────────────────────────────────────────────────────┤
│                    Layer 3: 前端展示层                            │
│  ├── UI 设计 (图标/颜色/布局)                                     │
│  ├── 交互反馈 (鼠标/动画/状态)                                    │
│  ├── 信息提示 (Tooltip/Toast/Modal/Banner)                       │
│  └── 代码架构 (Hooks/Stores/Components)                          │
└─────────────────────────────────────────────────────────────────┘
```
