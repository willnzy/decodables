## register

**简短回复**：
注册很简单！访问我们的注册页面，输入邮箱，验证后即可完成注册。新用户还能获得 100 积分赠送哦！

**详细回复**：
注册步骤：
1. 访问注册页面
2. 输入你的邮箱地址
3. 查收验证码邮件
4. 输入验证码完成注册

注册成功后，你将获得 100 永久积分作为新用户福利！

## login

**简短回复**：
点击网站右上角的「登录」按钮，输入邮箱和密码即可登录。

**详细回复**：
登录方式：
- 邮箱 + 密码登录
- 邮箱 + 验证码登录（更安全）

如果忘记密码，可以点击「忘记密码」重置。

## password_reset

**简短回复**：
在登录页点击「忘记密码」，输入邮箱，按照邮件指引重置密码。

**详细回复**：
重置密码步骤：
1. 在登录页点击「忘记密码」
2. 输入注册邮箱
3. 查收重置邮件
4. 点击链接设置新密码
