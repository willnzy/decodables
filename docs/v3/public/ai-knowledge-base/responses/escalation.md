## 自动转人工条件

### 敏感操作

| 操作 | 说明 |
|------|------|
| 退款请求 | 涉及资金，需人工确认 |
| 账号删除 | 不可逆操作 |
| 投诉 | 需要人工处理 |

### 情绪检测

| 信号 | 说明 |
|------|------|
| 多次表达不满 | 用户情绪需要安抚 |
| 使用负面词汇 | 可能需要人工介入 |
| 重复询问同一问题 | AI 可能无法满足需求 |

### 置信度

| 条件 | 处理 |
|------|------|
| 置信度 < 70% | 提供转人工选项 |
| 无法识别意图 | 提供转人工选项 |
