## 产品简介

Make Decodables 是一个在线 Decodable 创作工具，帮助教师和家长创建适合儿童阅读水平的教材。

---

## 核心功能

| 功能 | 描述 |
|------|------|
| 画布编辑器 | 拖拽式编辑，支持文字、图片、手绘 |
| AI 生图 | 根据描述生成插图 |
| AI 生成页面 | 自动生成页面内容 |
| OCR 识别 | 从图片提取文字 |
| 模板市场 | 浏览和使用社区模板 |
| 多格式导出 | PNG、PDF、SVG |
