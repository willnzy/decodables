## 主要界面

### Dashboard

项目管理中心，包含：

- 项目列表
- 文件夹管理
- 快速操作

### 编辑器

创作工作区，包含：

- 画布区域
- 工具栏
- 属性面板
- 页面缩略图

### Marketplace

模板市场，包含：

- 模板浏览
- 分类筛选
- 模板详情

## 常用操作

| 操作 | 快捷键 |
|------|--------|
| 撤销 | Ctrl/Cmd + Z |
| 重做 | Ctrl/Cmd + Shift + Z |
| 保存 | Ctrl/Cmd + S |
| 复制 | Ctrl/Cmd + C |
| 粘贴 | Ctrl/Cmd + V |
