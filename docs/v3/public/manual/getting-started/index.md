# 快速入门

> 欢迎使用 Make Decodables！本指南将帮助您在 5 分钟内创建第一本教育小书。

---

## 欢迎使用 Make Decodables

Make Decodables 是专为 K-2 教师设计的在线编辑工具，帮助您轻松创建个性化的 Phonics 和 Sight Words 教学材料。

### 您可以做什么

- 📚 创建 8 页迷你小书
- 🎨 使用专业设计的模板
- 🖼️ AI 智能生成插图
- 📝 添加自定义文字和图片
- 📄 导出高清 PDF 打印

---

## 第一步：创建账号

### 1.1 访问网站

打开浏览器，访问 [makedecodables.com](https://makedecodables.com)

### 1.2 点击注册

点击页面右上角的 **Sign Up** 按钮

### 1.3 输入邮箱

输入您的邮箱地址，然后点击 **Continue**

```
┌──────────────────────────────────┐
│  Create your account             │
│                                  │
│  Email: [your@email.com    ]     │
│                                  │
│  [Continue]                      │
│                                  │
│  Already have an account? Login  │
└──────────────────────────────────┘
```

### 1.4 验证邮箱

查收邮件，输入 6 位验证码

> 💡 验证码有效期 5 分钟，如未收到请检查垃圾邮件

### 1.5 设置密码

创建一个安全的密码（至少 8 位，包含字母和数字）

**恭喜！** 注册成功后您将获得 **100 积分** 用于体验 AI 功能。

## 第二步：创建第一个项目

### 2.1 进入 Dashboard

登录后，您将看到 Dashboard 页面

### 2.2 创建新项目

点击 **+ Create New** 按钮


### 2.3 选择模板

- **Blank**: 从空白页面开始
- **From Template**: 使用预设模板（推荐新手）

> 💡 推荐选择 **CVC Words** 模板快速开始

## 第三步：基础编辑

### 3.1 认识编辑器界面

```
┌────────────────────────────────────────────────────────────┐
│  [Save] [Undo] [Redo]              [Export]   [Settings]   │
├──────────┬────────────────────────────────┬────────────────┤
│          │                                │                │
│  素材库   │         画布区域               │    属性面板    │
│  --------│                                │                │
│  Templates│        ┌──────────┐          │  位置/大小     │
│  Images   │        │ 编辑区   │          │  颜色/字体     │
│  Text     │        └──────────┘          │  效果/样式     │
│  Shapes   │                                │                │
│  AI       │                                │                │
│          │                                │                │
├──────────┴────────────────────────────────┴────────────────┤
│  [1] [2] [3] [4] [5] [6] [7] [8]  ← 页面缩略图             │
└────────────────────────────────────────────────────────────┘
```

### 3.2 添加文字

1. 点击左侧 **Text** 标签
2. 选择文字样式（标题/正文）
3. 点击画布添加文字
4. 双击文字进行编辑

### 3.3 添加图片

1. 点击左侧 **Images** 标签
2. 选择：
   - **上传图片**: 从电脑上传
   - **素材库**: 选择预置素材
   - **AI 生成**: 输入描述自动生成

### 3.4 使用 AI 生成插图

1. 点击左侧 **AI** 标签
2. 选择 **Generate Image**
3. 输入图片描述，例如："A happy cat sitting on a mat"
4. 点击 **Generate**
5. 等待几秒，图片自动添加到画布

> ⚡ AI 生图消耗 5 积分/次

### 3.5 切换页面

点击底部的页面缩略图 [1]-[8] 切换不同页面

---

## 第四步：保存和导出

### 4.1 自动保存

您的作品会自动保存到云端，无需手动保存

> 看到 "Saved" 标志表示已保存

### 4.2 导出 PDF

1. 点击右上角 **Export** 按钮
2. 选择导出格式：
   - **PDF**: 适合打印
   - **PNG**: 单页图片
3. 选择质量：
   - **标准**: 适合屏幕查看
   - **高清**: 适合打印（推荐）
4. 点击 **Download**

### 4.3 打印小书

1. 打开下载的 PDF 文件
2. 选择 **双面打印** (如果打印机支持)
3. 按照折叠说明装订成小书
