# 创建第一个项目

> **版本**: 1.0.0
> **创建日期**: 2026-02-05
> **状态**: 🟡 待补充

---

## 操作步骤

### 1. 进入 Dashboard

登录后，你会看到 Dashboard 页面。

### 2. 点击「新建项目」

在右上角找到「新建项目」按钮。

### 3. 选择创建方式

| 选项 | 说明 |
|------|------|
| 空白画布 | 从零开始创作 |
| 使用模板 | 选择预设模板快速开始 |

### 4. 设置项目信息

- 项目名称
- 页面尺寸（Letter/A4/自定义）

### 5. 开始编辑

进入编辑器，开始你的创作！

---

## 快速上手

### 添加文字

1. 点击工具栏的「文字」
2. 在画布上点击
3. 输入文字内容

### 添加图片

1. 点击「图片」
2. 上传图片或使用 AI 生成

### 保存项目

- 项目自动保存
- 也可手动点击「保存」
