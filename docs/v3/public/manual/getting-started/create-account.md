## 注册步骤

### 1. 访问注册页

前往 [注册页面](https://foliaz.com/sign-up)

### 2. 输入邮箱

输入你的邮箱地址，点击「发送验证码」

### 3. 验证邮箱

- 查收邮件中的 6 位验证码
- 在页面输入验证码

### 4. 完成注册

- 设置密码（可选）
- 完成注册

## 常见问题

**Q: 收不到验证码？**

A: 请检查垃圾邮件文件夹，或尝试重新发送。

**Q: 可以修改注册邮箱吗？**

A: 注册后可在「账号设置」中修改。
