## 基本操作

### 调整大小

拖动图片角落的控制点

### 裁剪

1. 选中图片
2. 点击「裁剪」
3. 调整裁剪区域
4. 确认裁剪

### 旋转

拖动旋转控制点

---

## 图片效果

### 滤镜

| 滤镜 | 效果 |
|------|------|
| 原图 | 无滤镜 |
| 黑白 | 灰度效果 |
| 复古 | 怀旧色调 |

### 调整

| 参数 | 说明 |
|------|------|
| 亮度 | 明暗调整 |
| 对比度 | 对比度调整 |
| 饱和度 | 色彩饱和度 |

---

## 图片替换

1. 选中图片
2. 点击「替换」
3. 选择新图片
