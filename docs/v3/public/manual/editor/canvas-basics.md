## 画布导航

### 缩放

| 操作 | 方式 |
|------|------|
| 放大 | 滚轮向上 / Ctrl + |
| 缩小 | 滚轮向下 / Ctrl - |
| 适应窗口 | Ctrl + 0 |
| 100% | Ctrl + 1 |

### 平移

- 按住空格 + 拖动
- 使用滚动条

---

## 选择元素

### 单选

点击元素即可选中

### 多选

- Shift + 点击：添加到选择
- 拖动框选：框选多个元素

### 全选

Ctrl/Cmd + A

---

## 变换元素

### 移动

- 拖动选中的元素
- 方向键微调

### 缩放

拖动元素角落的控制点

### 旋转

拖动元素上方的旋转控制点

## 图层操作

| 操作 | 快捷键 |
|------|--------|
| 上移一层 | Ctrl + ] |
| 下移一层 | Ctrl + [ |
| 置于顶层 | Ctrl + Shift + ] |
| 置于底层 | Ctrl + Shift + [ |
