## 画笔工具

### 使用方法

1. 选择画笔工具
2. 设置画笔属性
3. 在画布上绘制

### 画笔属性

| 属性 | 说明 |
|------|------|
| 颜色 | 画笔颜色 |
| 粗细 | 线条宽度 |
| 透明度 | 线条透明度 |

---

## 橡皮擦

### 使用方法

1. 选择橡皮擦
2. 在画布上擦除

### 擦除模式

| 模式 | 说明 |
|------|------|
| 像素擦除 | 擦除绘制内容 |
| 对象擦除 | 删除整个对象 |

---

## 形状工具

### 可用形状

| 形状 | 说明 |
|------|------|
| 矩形 | 矩形/正方形 |
| 圆形 | 圆形/椭圆 |
| 三角形 | 三角形 |
| 线条 | 直线/箭头 |

### 绘制方法

1. 选择形状
2. 在画布上拖动绘制
3. 按住 Shift 绘制正形状
