## 编辑文字内容

1. 双击文字元素
2. 进入编辑模式
3. 修改文字内容
4. 点击外部完成

---

## 文字样式

### 字体

在属性面板选择字体

### 字号

| 方式 | 操作 |
|------|------|
| 输入数值 | 直接输入字号 |
| 增减按钮 | +/- 调整 |

### 颜色

点击颜色选择器，选择文字颜色

### 样式

| 样式 | 快捷键 |
|------|--------|
| 加粗 | Ctrl + B |
| 斜体 | Ctrl + I |
| 下划线 | Ctrl + U |

## 段落设置

### 对齐

| 选项 | 说明 |
|------|------|
| 左对齐 | 文字靠左 |
| 居中 | 文字居中 |
| 右对齐 | 文字靠右 |
| 两端对齐 | 两端对齐 |

### 行距

调整行与行之间的间距

### 字间距

调整字与字之间的间距
