## 通用操作

| 操作 | Windows | Mac |
|------|---------|-----|
| 保存 | Ctrl + S | Cmd + S |
| 撤销 | Ctrl + Z | Cmd + Z |
| 重做 | Ctrl + Shift + Z | Cmd + Shift + Z |
| 复制 | Ctrl + C | Cmd + C |
| 粘贴 | Ctrl + V | Cmd + V |
| 剪切 | Ctrl + X | Cmd + X |
| 全选 | Ctrl + A | Cmd + A |
| 删除 | Delete | Delete |
