## AI 生成图片

### 使用方法

1. 点击「AI 生图」
2. 输入图片描述
3. 选择生成风格
4. 点击「生成」
5. 从结果中选择

### 消耗

每次生成消耗 **5 积分**

### 提示技巧

| 技巧 | 说明 |
|------|------|
| 具体描述 | "一只橙色的猫在草地上" |
| 指定风格 | "卡通风格"、"水彩风格" |
| 简洁明了 | 避免过于复杂的描述 |

## AI 生成页面

### 使用方法

1. 点击「AI 生成页面」
2. 输入页面主题
3. 选择模板风格
4. 点击「生成」

### 消耗

每次生成消耗 **5 积分**

---

## OCR 文字识别

### 使用方法

1. 上传包含文字的图片
2. 点击「识别文字」
3. 复制或编辑识别结果

### 消耗

每次识别消耗 **10 积分**
