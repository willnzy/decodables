## 导入

### 支持的格式

| 格式 | 说明 |
|------|------|
| PNG/JPG | 作为图片导入 |
| SVG | 作为矢量图导入 |
| PDF | 作为页面导入 |

### 导入步骤

1. 点击「导入」
2. 选择文件
3. 确认导入设置
4. 完成导入

---

## 导出

### 导出格式

| 格式 | 说明 | 套餐要求 |
|------|------|----------|
| PNG | 位图格式 | 全部 |
| PDF | 文档格式 | 全部 |
| SVG | 矢量格式 | t2+ |

### 导出设置

| 选项 | 说明 |
|------|------|
| 分辨率 | 72/150/300 DPI |
| 页面范围 | 全部/当前/指定 |

### 导出步骤

1. 点击「导出」
2. 选择格式
3. 设置选项
4. 点击「下载」
