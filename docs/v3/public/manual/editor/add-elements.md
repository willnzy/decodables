## 添加文字

### 步骤

1. 点击工具栏「文字」
2. 选择文字类型
3. 在画布上点击
4. 输入内容

### 文字类型

| 类型 | 用途 |
|------|------|
| 标题 | 大号醒目文字 |
| 正文 | 常规段落文字 |
| 标签 | 小号注释文字 |

---

## 添加图片

### 上传图片

1. 点击「图片」→「上传」
2. 选择本地图片
3. 图片添加到画布

### AI 生成图片

1. 点击「图片」→「AI 生成」
2. 输入描述文字
3. 选择生成的图片

### 从素材库选择

1. 点击「图片」→「素材库」
2. 浏览或搜索
3. 点击使用

---

## 添加形状

1. 点击「形状」
2. 选择形状类型
3. 在画布上拖动绘制
