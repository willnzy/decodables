## 项目操作

### 重命名

1. 点击项目名称
2. 输入新名称
3. 按 Enter 确认

### 复制

1. 点击项目菜单
2. 选择「复制」
3. 生成副本

### 移动

1. 拖动项目到目标文件夹
2. 或使用「移动到」菜单

### 删除

1. 点击项目菜单
2. 选择「删除」
3. 确认删除
