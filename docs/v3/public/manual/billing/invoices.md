## 查看发票

在「账号设置」→「账单」中查看所有发票

---

## 发票内容

| 项目 | 说明 |
|------|------|
| 发票号 | 唯一标识 |
| 日期 | 付款日期 |
| 金额 | 付款金额 |
| 项目 | 订阅/积分 |
| 状态 | 已付/待付 |

---

## 下载发票

点击发票旁的「下载」按钮获取 PDF

---

## 发票信息

### 修改账单信息

1. 进入「账号设置」
2. 点击「账单信息」
3. 修改公司名称、地址等
4. 保存

---

## 常见问题

**Q: 可以开具增值税发票吗？**

A: 目前仅支持国际通用发票格式

**Q: 发票丢失怎么办？**

A: 在账单历史中重新下载
