## 通知类型

| 类型 | 说明 |
|------|------|
| 系统通知 | 功能更新、维护通知 |
| 订阅通知 | 续费提醒、到期提醒 |
| 活动通知 | 促销、新功能 |

---

## 通知渠道

### 站内通知

- 始终开启
- 在网站内查看

### 邮件通知

| 选项 | 默认 |
|------|------|
| 系统通知 | 开启 |
| 订阅通知 | 开启 |
| 营销邮件 | 关闭 |

---

## 修改设置

1. 进入「设置」→「通知」
2. 选择要修改的通知类型
3. 开启或关闭
4. 保存

---

## 退订邮件

点击邮件底部的「退订」链接
