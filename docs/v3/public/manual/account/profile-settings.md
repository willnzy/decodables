## 访问设置

点击头像 → 「设置」

---

## 基本信息

### 可修改项

| 项目 | 说明 |
|------|------|
| 头像 | 上传个人头像 |
| 昵称 | 显示名称 |
| 个人简介 | 简短介绍 |

---

## 账号信息

### 邮箱

- 当前绑定邮箱
- 点击「修改」更换邮箱
- 需要验证新邮箱

### 密码

- 点击「修改密码」
- 输入当前密码
- 设置新密码

## 偏好设置

| 设置 | 选项 |
|------|------|
| 语言 | 中文/English |
| 主题 | 浅色/深色/跟随系统 |
| 时区 | 自动检测/手动选择 |
