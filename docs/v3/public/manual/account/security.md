## 密码管理

### 修改密码

1. 进入「设置」→「安全」
2. 点击「修改密码」
3. 输入当前密码
4. 设置新密码
5. 确认保存

### 密码要求

- 最少 8 个字符
- 包含字母和数字

## 账号安全

### 账号代码

你的账号代码用于：
- 联系客服时验证身份
- 敏感操作二次确认

> 查看位置：设置 → 账号 → 账号代码

---

## 删除账号

### 步骤

1. 进入「设置」→「账号」
2. 滚动到底部
3. 点击「删除账号」
4. 输入密码确认
5. 确认删除

### 注意

- 账号删除后无法恢复
- 所有数据将被永久删除
- 有效订阅将被取消
