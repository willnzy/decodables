## 购买步骤

### 1. 选择模板

在 Marketplace 中找到想要的模板

### 2. 点击购买

点击「购买」或「使用」按钮

### 3. 确认支付

| 支付方式 | 说明 |
|----------|------|
| 信用卡 | 通过 Stripe 支付 |
| PayPal | 即将支持 |

### 4. 开始使用

购买后模板会出现在你的 Dashboard
