## 浏览方式

### 分类浏览

| 分类 | 说明 |
|------|------|
| 热门 | 最受欢迎的模板 |
| 最新 | 最近上传的模板 |
| 免费 | 免费使用的模板 |
| 主题 | 按主题分类 |

### 搜索

在搜索框输入关键词

### 筛选

| 筛选项 | 选项 |
|--------|------|
| 价格 | 免费 / 付费 |
| 类型 | 单页 / 多页 |
| 风格 | 卡通 / 简约 / 其他 |
