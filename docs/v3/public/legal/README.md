## 内容要点

### terms-of-service.md

- 服务范围和使用条件
- 用户责任和行为准则
- 知识产权（用户内容、平台内容）
- 免责声明
- 服务终止条款
- 争议解决

### privacy-policy.md

- 数据收集范围
- 数据使用目的
- 数据存储和安全
- 第三方共享
- Cookie 使用
- 用户权利（访问、更正、删除）
- 联系方式

### billing-policy.md

- 套餐和定价
- 订阅周期
- 自动续费
- 升级/降级
- 退款政策
- 价格变更通知

### content-guidelines.md

- 禁止内容类型
- 内容审核标准
- 违规处理措施
- 申诉流程

## 更新要求

1. **版本标识** - 每次更新需标注版本和日期
2. **变更通知** - 重大变更需提前通知用户
3. **法务审核** - 重要条款变更需法务确认
4. **多语言** - 未来需要本地化版本
