## 概述

定义系统监控指标和告警规则。

---

## 监控指标

### 应用指标

| 指标 | 阈值 | 告警级别 |
|------|------|----------|
| API 响应时间 | > 2s | P2 |
| 错误率 | > 5% | P1 |
| 请求量 | 异常波动 | P2 |

### 基础设施指标

| 指标 | 阈值 | 告警级别 |
|------|------|----------|
| CPU 使用率 | > 80% | P2 |
| 内存使用率 | > 80% | P2 |
| 磁盘使用率 | > 90% | P1 |

### 数据库指标

| 指标 | 阈值 | 告警级别 |
|------|------|----------|
| 连接数 | > 80% | P2 |
| 慢查询 | > 1s | P2 |
| 复制延迟 | > 10s | P1 |

---

## 告警级别

| 级别 | 定义 | 响应时间 |
|------|------|----------|
| P0 | 服务完全不可用 | 立即 |
| P1 | 核心功能受损 | 15 分钟 |
| P2 | 非核心功能受损 | 1 小时 |
| P3 | 潜在问题 | 24 小时 |

---

## 告警通知

| 级别 | 通知渠道 |
|------|----------|
| P0 | 电话 + 短信 + Slack |
| P1 | 短信 + Slack |
| P2 | Slack |
| P3 | 邮件 |
