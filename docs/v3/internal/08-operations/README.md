## deployment.md 内容大纲

```markdown
## 环境配置
- 开发环境
- 预发布环境
- 生产环境

## 发布流程
1. PR Review
2. CI 检查
3. 预发布验证
4. 生产部署
5. 冒烟测试

## 回滚流程
- Vercel: 一键回滚到上一版本
- Railway: 重新部署上一版本
- 数据库: 按需回滚迁移
```

## monitoring.md 内容大纲

```markdown
## 监控指标
- 前端：Core Web Vitals, Error Rate
- 后端：API 延迟, 错误率, 吞吐量
- 数据库：连接数, 查询延迟

## 告警规则
- P0：API 全部不可用
- P1：错误率 > 5%
- P2：延迟 > 2s

## 看板
- 业务看板
- 系统看板
```
