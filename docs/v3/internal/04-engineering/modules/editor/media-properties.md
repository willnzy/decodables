## 概述

编辑器左侧 Media 面板和右侧 Properties 面板的技术设计。

---

## Media 面板 (左侧)

### 功能区域

1. **页面列表**
   - 页面缩略图
   - 拖拽排序
   - 添加/删除页面

2. **素材库**
   - 分类浏览
   - 搜索
   - 拖拽添加到画布

3. **模板**
   - 模板预览
   - 一键应用

4. **上传**
   - 图片上传
   - 文件导入

---

## Properties 面板 (右侧)

### 根据选中元素动态显示

| 元素类型 | 显示属性 |
|----------|----------|
| 图片 | 尺寸、位置、透明度、滤镜、裁切 |
| 文字 | 字体、大小、颜色、对齐、行高 |
| 形状 | 尺寸、填充色、边框、圆角 |
| 画笔 | 笔触宽度、颜色、透明度 |
| 无选中 | 页面属性 (尺寸、背景) |

### 属性分组

```
基础属性
├── 位置 (X, Y)
├── 尺寸 (宽, 高)
├── 旋转角度
└── 透明度

样式属性
├── 填充
├── 边框
└── 阴影

特定属性 (按类型)
└── ...
```

## 响应式行为

| 屏幕 | Media 面板 | Properties 面板 |
|------|-----------|----------------|
| Desktop | 固定左侧 | 固定右侧 |
| Tablet | 可折叠 | 可折叠 |
| Mobile | 底部 Sheet | 底部 Sheet |
