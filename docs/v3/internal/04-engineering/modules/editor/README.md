## 模块概览

编辑器是产品的核心模块，用于创建和编辑 Decodables 内容。

## 对应代码

| 仓库 | 目录 |
|------|------|
| 后端 | `domains/creation/`, `domains/templates/`, `domains/export/` |
| 前端 | `app/create/`, `@business/stores/editor/` |

## 核心功能

- Canvas 画布渲染（Fabric.js）
- 媒体管理（图片、文字、形状）
- 模板系统
- 导出功能（PNG、PDF）
