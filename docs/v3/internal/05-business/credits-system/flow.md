| 方式 | 积分类型 | 数量 | 说明 |

| 注册赠送 | 永久 | 100 | 新用户一次性 |

## 二、积分消费

### 2.1 消费成本

| 功能 | 消耗 | 说明 |
|------|------|------|
| AI 生图 | 5 | 每次生成 |
| AI 生成页面 | 5 | 每页 |
| OCR 识别 | 10 | 每次识别 |

### 2.2 扣费顺序

```
扣费优先级: 月度积分 → 永久积分

示例 1: 月度足够
- 余额: 月度 50, 永久 100
- 消耗: 5
- 结果: 月度 45, 永久 100

示例 2: 月度不足
- 余额: 月度 3, 永久 100
- 消耗: 5
- 结果: 月度 0, 永久 98
```

## 三、积分过期

### 3.1 月度积分重置

| 事件 | 处理 |
|------|------|
| 订阅续期 | 清零旧月度积分，发放新月度积分 |
| 订阅取消 | 周期结束时清零月度积分 |
| 降级 | 周期结束时清零月度积分 |

### 3.2 重置流程

```
订阅周期结束 (invoice.paid)
       │
       ▼
┌─────────────────────────────────────────┐
│ 1. 记录 monthly_reset (清零剩余月度)      │
│ 2. 记录 subscription_grant (发放新月度)   │
└─────────────────────────────────────────┘
```

### 3.3 永久积分

- **永不过期**
- 账户删除后失效
- 不可转让

## 四、特殊场景

### 4.1 升级补发

```
用户从 t2 升级到 t3 (月中升级)
- t2 月度积分: 100
- t3 月度积分: 200
- 补发: 200 - 100 = 100 (按比例计算)
```

### 4.2 降级处理

```
用户从 t3 降级到 t2 (周期结束)
- 清零当前月度积分
- 下周期发放 t2 的 100 月度积分
```

### 4.3 取消订阅

```
用户取消订阅 (周期结束)
- 清零月度积分
- 永久积分保留
- Tier 降为 t1
```

### 4.4 退款处理

```
用户申请退款
- 如果积分已使用 > 退款金额对应积分，拒绝退款
- 退款成功后扣除对应积分
```

## 五、交易记录

### 5.1 记录内容

每次积分变动都会记录：
- 交易类型 (TransactionType)
- 变动金额 (正/负)
- 变动前后余额快照
- 关联 ID (订单号等)
- 描述信息

### 5.2 交易类型

**增加**:
- `signup_bonus` - 注册赠送
- `subscription_grant` - 订阅发放
- `purchase` - 购买充值
- `refund` - 退款返还
- `admin_adjustment` - 管理员调整

**扣除**:
- `ai_generation` - AI 生图
- `smart_scan` - OCR 识别
- `monthly_reset` - 月度重置
- `monthly_credits_cleared` - 月度清零
