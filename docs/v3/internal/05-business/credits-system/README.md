## 概述

系统使用双积分类型机制。

## 积分类型

| 类型 | 来源 | 有效期 | 扣费优先级 |
|------|------|--------|------------|
| **月度积分** | 订阅会员每月自动发放 | 每月重置，不累积 | **先扣** |
| **永久积分** | 注册赠送 / 充值购买 | **永久有效** | 后扣 |

## 扣费顺序

```
credits_monthly → credits_permanent
```

## 注册赠送

- t1 用户注册赠送 100 永久积分
