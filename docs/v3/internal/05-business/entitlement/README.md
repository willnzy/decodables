## 权限评估流程（目标）

```
用户请求
    │
    ▼
┌─────────────────┐
│ L0: Kill Switch │ ── 关闭 ──▶ 返回 disabled
└────────┬────────┘
         │ 开启
         ▼
┌─────────────────┐
│ L1: Feature Flag│ ── 关闭 ──▶ 返回 disabled
└────────┬────────┘
         │ 开启
         ▼
┌─────────────────┐
│ L2: User Override│ ── 有 ──▶ 返回 Override 值
└────────┬────────┘
         │ 无
         ▼
┌─────────────────┐
│ L3: Tier Config │ ── 返回 Tier 基础权限
└─────────────────┘
```
