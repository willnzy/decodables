## 二、权益详情

### 2.1 t1 (Free Plan)

**适合**: 体验用户、轻度使用者

| 权益 | 说明 |
|------|------|
| 项目数量 | 最多 3 个项目 |
| 存储空间 | 100 MB |
| 导出 | 带水印 |
| 模板 | 基础免费模板 |
| AI 功能 | 仅 AI 生图 (消耗永久积分) |
| 注册赠送 | 100 永久积分 |

### 2.2 t2 (Starter Plan)

**适合**: 教师、轻度创作者

| 权益 | 说明 |
|------|------|
| 项目数量 | 最多 50 个项目 |
| 存储空间 | 5 GB |
| 导出 | 无水印 |
| 模板 | 全部模板 |
| AI 功能 | 全部 AI 功能 |
| 月度积分 | 100 积分/月 |
| 批量导出 | ✅ 支持 |
| 高清导出 | ✅ 支持 |

### 2.3 t3 (Pro Plan)

**适合**: 专业创作者、频繁使用者

| 权益 | 说明 |
|------|------|
| 项目数量 | 无限 |
| 存储空间 | 20 GB |
| 导出 | 无水印 |
| 模板 | 全部模板 + 抢先体验 |
| AI 功能 | 全部 AI 功能 + 优先队列 |
| 月度积分 | 200 积分/月 |
| AI 生图数量 | 最多 4 张/次 |
| 优先支持 | ✅ |

## 四、配额限制

### 4.1 项目配额

| Tier | 项目数量 | 达到上限后 |
|------|----------|------------|
| t1 | 3 | 提示升级 |
| t2 | 50 | 提示升级 |
| t3 | 无限 | - |

### 4.2 存储配额

| Tier | 存储空间 | 达到上限后 |
|------|----------|------------|
| t1 | 100 MB | 无法上传新文件 |
| t2 | 5 GB | 无法上传新文件 |
| t3 | 20 GB | 无法上传新文件 |

**存储计算**:
- 上传的图片
- 项目缩略图
- 导出的文件
