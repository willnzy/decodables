## 一、产品定位

### 1.1 一句话描述

**Make Decodables** - 面向教育工作者的 AI 驱动 Mini Book 创作工具。

### 1.2 产品类型

| 维度 | 定位 |
|------|------|
| 产品形态 | Web SaaS |
| 目标市场 | 全球 (英语为主) |
| 商业模式 | Freemium + 订阅 |
| 核心技术 | AI 生成 + 在线编辑 |

## 二、目标用户

### 2.1 主要用户

| 用户群体 | 描述 | 占比 |
|----------|------|------|
| 小学教师 | K-5 教师，制作阅读材料 | 60% |
| 家长 | 在家教育，亲子阅读 | 25% |
| 教育内容创作者 | 博主、自媒体 | 15% |

### 2.2 用户画像

**核心用户: Emily (小学教师)**
- 年龄: 30-45 岁
- 需求: 快速制作个性化阅读材料
- 痛点: 设计能力有限，时间紧张
- 期望: 简单易用，专业效果

### 2.3 使用场景

| 场景 | 描述 |
|------|------|
| 课堂教学 | 制作字母、数字学习材料 |
| 家庭作业 | 个性化阅读练习 |
| 亲子阅读 | 定制化绘本故事 |

## 四、差异化优势

### 4.1 竞品对比

| 特性 | Make Decodables | Canva | Book Creator |
|------|-----------------|-------|--------------|
| 教育专注 | ✅ 专注 K-5 | ❌ 通用 | ✅ 教育 |
| AI 生成 | ✅ 深度集成 | 🟡 基础 | ❌ 无 |
| Mini Book | ✅ 专业 | ❌ 通用 | 🟡 基础 |
| 价格 | $$$ | $$$$ | $$$ |

### 4.2 核心差异

1. **教育专注**: 专为 K-5 教育设计的素材和模板
2. **AI 原生**: AI 生成深度集成到创作流程
3. **Mini Book 专业**: 8 页小书格式，便于打印和分发

## 六、产品原则

### 6.1 设计原则

1. **教育优先**: 所有功能服务于教育场景
2. **简单至上**: 功能简单，学习曲线平缓
3. **AI 增强**: AI 是助手，不是替代
4. **快速出成果**: 最短路径达成目标

### 6.2 技术原则

1. **Web 优先**: 无需安装，跨平台
2. **性能优先**: 编辑器流畅，响应迅速
3. **数据安全**: 用户内容安全存储
4. **可扩展**: 架构支持未来增长
