## 模板说明

### 状态定义

| 状态 | 含义 |
|------|------|
| 🟢 已实现 | 功能已上线 |
| 🟡 开发中 | 正在开发 |
| 📋 计划中 | 已规划，未开始 |

### 同步范围

| 标签 | 含义 |
|------|------|
| [fullstack] | 前后端都需要了解 |
| [backend] | 主要涉及后端 |
| [frontend] | 主要涉及前端 |
