# ADR 模板 - 架构决策记录

> **版本**: 1.0.0
> **创建日期**: 2026-02-05

---

## 使用说明

ADR (Architecture Decision Record) 用于记录重要的技术决策。使用时复制下方模板并填写。

---

## 模板

```markdown
# ADR-XXXX: [决策标题]

> **状态**: [草稿/提议/已接受/已废弃/已替代]
> **日期**: YYYY-MM-DD
> **作者**: [作者名]
> **替代**: [如果替代了其他 ADR，写 ADR-XXXX]

---

## 上下文

描述问题背景和技术挑战：
- 当前面临什么问题？
- 有哪些约束条件？
- 有哪些相关的技术背景？

## 决策

清晰陈述做出的决策：
- 我们决定采用 [方案名称]
- 核心要点是...

## 考虑的方案

### 方案 A: [方案名称]

**描述**: ...

**优点**:
- ...

**缺点**:
- ...

### 方案 B: [方案名称]

**描述**: ...

**优点**:
- ...

**缺点**:
- ...

### 方案 C: [方案名称]（如有）

...

## 选择理由

解释为什么选择了最终方案：
- 符合 [某某原则/目标]
- 相比其他方案的优势是...
- 可接受的权衡是...

## 影响

### 正面影响

- ...

### 负面影响

- ...

### 需要的行动

- [ ] 行动 1
- [ ] 行动 2

## 相关链接

- [相关文档](link)
- [参考资料](link)
```

---

## 状态说明

| 状态 | 含义 |
|------|------|
| 草稿 | 正在撰写中 |
| 提议 | 等待评审 |
| 已接受 | 决策已通过并实施 |
| 已废弃 | 不再适用 |
| 已替代 | 被新的 ADR 替代 |

---

## 命名规范

- 文件名: `adr-XXXX-short-title.md`
- XXXX 为 4 位序号，从 0001 开始
- 标题使用短横线分隔的小写英文

**示例**:
- `adr-0001-use-ddd-architecture.md`
- `adr-0002-database-driven-config.md`
- `adr-0003-jwt-authentication.md`

---
