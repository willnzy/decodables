## 目录说明

文档模板库，用于创建新文档时保持一致性。

## 可用模板

### 产品文档

| 模板 | 用途 | 适用目录 |
|------|------|----------|
| [feature-spec-template.md](feature-spec-template.md) | 功能规格文档 | `02-product/features/` |
| [page-design-template.md](page-design-template.md) | 页面设计文档 | `02-product/pages/` |

### 技术文档

| 模板 | 用途 | 适用目录 |
|------|------|----------|
| [module-readme-template.md](module-readme-template.md) | 模块 README | `04-engineering/modules/` |

| [adr-template.md](adr-template.md) | 架构决策记录 | `04-engineering/architecture/decisions/` |

### 公开内容

| 模板 | 用途 | 适用目录 |
|------|------|----------|
| [faq-template.md](faq-template.md) | FAQ 文档 | `public/faq/` |
| [news-template.md](news-template.md) | News 文章 | `public/news/` |

## 使用说明

1. 找到对应的模板文件
2. 复制模板中的 Markdown 内容
3. 根据实际情况填充内容
4. 遵循模板中的格式和规范

## 模板规范

所有模板都遵循以下规范：

1. **元数据**: 包含同步范围、状态、更新日期
2. **结构**: 使用统一的章节结构
3. **状态标记**: 使用统一的状态图标
4. **同步标签**: [fullstack] / [backend] / [frontend]
