| 模板 | 用途 | 状态 |

| `faq-template.md` | FAQ 文档模板 | ✅ 可用 |
| `news-template.md` | News 文章模板 | ✅ 可用 |
| `adr-template.md` | ADR 决策记录模板 | 📋 待创建 |
| `module-readme-template.md` | 模块 README 模板 | 📋 待创建 |
| `feature-spec-template.md` | 功能规格模板 | 📋 待创建 |

## 使用说明
