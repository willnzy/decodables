# 页面设计模板

> **版本**: 1.0.0
> **创建日期**: 2026-02-05

---

## 使用说明

此模板用于创建 `02-product/pages/{scope}/{page}.md` 文件。

---

## 模板

```markdown
# {页面名称}页面设计

> **同步范围**: [frontend]
> **状态**: 🟢 已实现 / 🟡 开发中 / 📋 计划中
> **路由**: `/path/to/page`
> **最后更新**: YYYY-MM-DD

---

## 一、页面概述

### 1.1 页面用途

简要描述页面的目的（1-2 句话）。

### 1.2 用户入口

- 从 {页面 A} 点击 {按钮} 进入
- 直接访问 URL

### 1.3 访问权限

| Tier | 权限 |
|------|------|
| t1 (Free) | ✅ / ❌ / 部分 |
| t2 (Starter) | ✅ |
| t3 (Pro) | ✅ |
```

```
## 三、页面状态

### 3.1 加载状态

- **Loading**: 显示骨架屏 / 加载动画
- **Error**: 显示错误提示，提供重试按钮
- **Empty**: 显示空状态引导

### 3.2 数据依赖

| 数据 | 来源 | 加载时机 |
|------|------|----------|
| 数据 1 | API `/xxx` | 页面加载 |
| 数据 2 | Store | 实时 |

---

## 四、交互设计

### 4.1 用户操作

| 操作 | 触发条件 | 结果 |
|------|----------|------|
| 点击按钮 A | ... | 跳转到页面 B |
| 提交表单 | 填写完成后 | 显示成功提示 |

### 4.2 动效

| 场景 | 动效 |
|------|------|
| 页面进入 | fade-in 200ms |
| 列表加载 | stagger 50ms |

---

## 五、响应式设计

### 5.1 断点

| 断点 | 宽度 | 布局变化 |
|------|------|----------|
| Mobile | < 768px | 单列布局 |
| Tablet | 768px - 1024px | 双列布局 |
| Desktop | > 1024px | 三列布局 |

### 5.2 移动端适配

- 底部导航固定
- 触摸目标 ≥ 44px
- 使用 Sheet 代替 Dialog
```
