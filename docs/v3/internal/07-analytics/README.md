## 核心指标框架（参考）

### 北极星指标

| 指标 | 定义 | 计算方式 |
|------|------|----------|
| WAU | 周活跃用户 | 7 天内有编辑行为的用户数 |
| 付费转化率 | 免费 → 付费比例 | 新增付费 / 7 天前注册用户 |

### 关键漏斗

```
注册 → 首次编辑 → 首次导出 → 7 日回访 → 付费
```

### 健康指标

| 类别 | 指标 |
|------|------|
| 获客 | DAU, WAU, 新注册 |
| 活跃 | 编辑次数, 导出次数, 会话时长 |
| 留存 | D1, D7, D30 留存 |
| 变现 | MRR, ARPU, 付费率 |
