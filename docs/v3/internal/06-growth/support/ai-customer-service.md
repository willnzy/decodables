## 功能范围

### 支持的场景

| 场景 | 处理方式 |
|------|----------|
| 产品咨询 | 知识库回答 |
| 功能引导 | 步骤指引 |
| 常见问题 | FAQ 匹配 |
| 账号问题 | 简单自助 |

### 不支持的场景

| 场景 | 处理方式 |
|------|----------|
| 退款请求 | 转人工 |
| 复杂投诉 | 转人工 |
| 安全问题 | 转人工 |

---

## 技术方案

| 组件 | 技术 |
|------|------|
| 意图识别 | LLM / NLU |
| 知识库 | 向量数据库 |
| 回复生成 | RAG |

---

## 转人工条件

| 条件 | 说明 |
|------|------|
| 用户主动要求 | 直接转人工 |
| 置信度低 | < 70% 置信度 |
| 敏感问题 | 退款、投诉等 |
| 重复提问 | 同问题 3 次 |
