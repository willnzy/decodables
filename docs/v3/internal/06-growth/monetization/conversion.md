## 概述

定义免费用户向付费用户转化的策略。

---

## 转化漏斗

```
访客 → 注册 → 激活 → 留存 → 付费 → 续费
```

| 阶段 | 当前转化率 | 目标 |
|------|------------|------|
| 访客 → 注册 | - | > 10% |
| 注册 → 激活 | - | > 50% |
| 激活 → 付费 | - | > 5% |

---

## 转化策略

### 1. 付费墙设计

| 功能 | t1 限制 | 付费解锁 |
|------|---------|----------|
| AI 生图 | 有限次数 | 无限制 |
| 导出格式 | 基础 | 高级 |
| 存储空间 | 限制 | 扩大 |

### 2. 升级提示

| 触发点 | 提示内容 |
|--------|----------|
| 积分不足 | 升级获得更多积分 |
| 功能受限 | 展示付费功能价值 |
| 使用高频 | 推荐适合的套餐 |

### 3. 限时优惠

| 类型 | 策略 |
|------|------|
| 首次付费 | 首月折扣 |
| 年付优惠 | 节省 X 个月 |
| 节日促销 | 限时特价 |
