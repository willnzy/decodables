## 概述

定义用户邀请计划，通过老用户带新用户实现增长。

---

## 奖励机制

### 邀请人奖励

| 条件 | 奖励 |
|------|------|
| 被邀请人注册 | 50 永久积分 |
| 被邀请人付费 | 额外 100 积分 |

### 被邀请人奖励

| 条件 | 奖励 |
|------|------|
| 通过邀请链接注册 | 额外 50 积分 |

---

## 邀请流程

```
1. 用户获取专属邀请链接
2. 分享给好友
3. 好友点击链接注册
4. 双方自动获得奖励
```

---

## 防滥用机制

| 规则 | 说明 |
|------|------|
| IP 限制 | 同 IP 限制注册数 |
| 设备限制 | 同设备限制注册数 |
| 积分上限 | 每月邀请奖励上限 |
