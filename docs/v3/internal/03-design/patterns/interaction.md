## 动画规范

### 过渡时长

| 类型 | 时长 | 用途 |
|------|------|------|
| fast | 150ms | 悬停、按下 |
| normal | 200ms | 展开、折叠 |
| slow | 300ms | 页面切换、模态框 |

### 缓动函数

```css
/* 默认 */
transition-timing-function: ease-out;

/* 弹性 */
transition-timing-function: cubic-bezier(0.34, 1.56, 0.64, 1);
```

---

## 反馈模式

### 视觉反馈

| 操作 | 反馈 |
|------|------|
| 悬停 | 背景色变化 / 阴影 |
| 按下 | scale(0.95) |
| 加载 | Spinner / 骨架屏 |
| 成功 | Toast / 图标变化 |
| 错误 | Toast / 边框变红 |

### 触觉反馈 (Mobile)

- 点击: 轻触反馈
- 长按: 振动反馈

---

## 手势

### 支持的手势

| 手势 | 场景 | 操作 |
|------|------|------|
| 点击 | 通用 | 选择/确认 |
| 长按 | 列表项 | 多选/上下文菜单 |
| 滑动 | 列表 | 删除/归档 |
| 拖拽 | 页面排序 | 重新排序 |
| 双指缩放 | 画布 | 缩放视图 |
