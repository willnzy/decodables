## 概述

用户反馈类组件的设计规范。

---

## 组件列表

### Dialog 对话框
- 基础对话框
- 确认对话框
- 表单对话框
- 全屏对话框

### Toast 提示
- 成功提示
- 错误提示
- 警告提示
- 信息提示

### Alert 警告
- 内联警告
- 页面级警告

### Loading 加载
- 全屏加载
- 按钮加载
- 骨架屏

### Progress 进度
- 进度条
- 环形进度

---

## 使用场景

| 组件 | 使用场景 |
|------|----------|
| Dialog | 需要用户确认或输入 |
| Toast | 操作结果反馈 |
| Alert | 重要信息提示 |
| Loading | 异步操作等待 |
