## 组件列表

### Table 表格
- 基础表格
- 可排序
- 可筛选
- 分页

### List 列表
- 基础列表
- 带图标列表
- 可选择列表

### Badge 徽章
- 状态徽章
- 数字徽章
- 点状徽章

### Tag 标签
- 基础标签
- 可删除标签
- 颜色变体

### Tooltip 提示
- 悬停提示
- 方向控制

### Empty 空状态
- 无数据
- 无搜索结果
- 引导操作

---

## Badge 颜色

| 类型 | 颜色 | 用途 |
|------|------|------|
| success | green | 成功/活跃 |
| warning | yellow | 警告/待处理 |
| error | red | 错误/过期 |
| info | blue | 信息 |
| neutral | gray | 默认 |
