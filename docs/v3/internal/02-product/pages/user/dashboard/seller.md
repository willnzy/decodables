```
│ 可提现余额        $456.00           │
└─────────────────────────────────────┘
```

### 提现

**提现条件**：
- 最低提现金额：$50
- 提现周期：每月 1 次

**提现流程**：
1. 点击"申请提现"
2. 输入提现金额
3. 确认收款账户 (PayPal/银行)
4. 提交申请
5. 3-5 个工作日到账

## 卖家认证

### 认证要求

- 完善个人资料
- 绑定收款账户
- 同意卖家协议

### 认证流程

1. 填写基本信息
2. 上传身份证明 (可选)
3. 绑定 PayPal 或银行账户
4. 审核 (1-3 工作日)
5. 认证通过，开始销售
