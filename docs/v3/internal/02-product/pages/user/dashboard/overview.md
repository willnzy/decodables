## 概述

Dashboard 页面的整体布局设计，包括侧边栏导航和内容区域。

---

## 桌面端布局 (≥768px)

### 区域划分

| 区域 | 位置 | 尺寸 | 说明 |
|------|------|------|------|
| Header | 顶部 | 64px 高 | Logo、搜索、通知、头像 |
| Sidebar | 左侧 | 240px 宽 | 导航菜单、工作区切换 |
| Main | 右侧 | 自适应 | 内容区域 |

### Sidebar 组成

```
┌─────────────────────┐
│ [工作区切换器 ▼]    │
├─────────────────────┤
│ 📁 项目             │
│ 🎨 素材             │
│ ⭐ 收藏             │
│ 🗑️ 垃圾箱           │
├─────────────────────┤
│ 工作区              │
│   👤 个人           │
│   👥 团队 A         │
├─────────────────────┤
│ 💰 卖家中心         │
├─────────────────────┤
│ ┌─────────────────┐ │
│ │ 升级 Pro 🚀     │ │  ← 升级 CTA (仅 t1/t2)
│ └─────────────────┘ │
└─────────────────────┘
```

## 移动端布局 (<768px)

### 区域变化

| 区域 | 变化 |
|------|------|
| Header | 简化，添加菜单按钮 |
| Sidebar | 变为抽屉式，点击菜单展开 |
| Main | 全宽显示 |
| Bottom Nav | 新增底部导航栏 |

### 底部导航

```
┌───────────────────────────────────────┐
│  [项目]  [素材]  [+新建]  [收藏]  [我的] │
└───────────────────────────────────────┘
```

---

## 内容区域通用结构

### Header Bar

```
┌─────────────────────────────────────────────────┐
│ 📁 项目 (32)     [🔍搜索] [筛选▼] [≡列表][⊞网格] │
└─────────────────────────────────────────────────┘
```

- 标题 + 数量
- 搜索框
- 筛选器 (类型、日期、标签)
- 视图切换 (网格/列表)

### Content Grid

```
┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│ Card 1 │ │ Card 2 │ │ Card 3 │ │ Card 4 │
└────────┘ └────────┘ └────────┘ └────────┘
┌────────┐ ┌────────┐ ┌────────┐
│ Card 5 │ │ Card 6 │ │ + 新建 │
└────────┘ └────────┘ └────────┘
```

- 响应式网格 (1-4 列)
- 最后显示"新建"卡片

---

## 响应式断点

| 断点 | Sidebar | 网格列数 |
|------|---------|----------|
| <768px | 抽屉式 | 1-2 列 |
| 768-1023px | 折叠图标 | 2-3 列 |
| ≥1024px | 完整展开 | 3-4 列 |
