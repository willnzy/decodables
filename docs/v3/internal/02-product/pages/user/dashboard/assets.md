## 上传素材

### 入口

1. 拖放文件到页面
2. 点击"上传"按钮
3. 粘贴图片

### 支持格式

| 类型 | 格式 |
|------|------|
| 图片 | PNG, JPG, GIF, SVG, WebP |
| 文档 | PDF (自动转图片) |

### 上传限制

| 项目 | 限制 |
|------|------|
| 单文件大小 | 10 MB |
| 总存储 (t1) | 100 MB |
| 总存储 (t2) | 1 GB |
| 总存储 (t3) | 10 GB |

## 发布到市场

### 发布对话框

```
┌─────────────────────────────────────┐
│ 发布素材到市场                       │
├─────────────────────────────────────┤
│ 预览图                               │
│ ┌─────────────────────────────────┐ │
│ │        [素材预览]               │ │
│ └─────────────────────────────────┘ │
│                                     │
│ 标题 [素材标题输入框]                │
│                                     │
│ 描述 [描述文本框...]                 │
│                                     │
│ 分类 [选择分类 ▼]                    │
│                                     │
│ 标签 [标签1] [标签2] [+ 添加]        │
│                                     │
│ 定价                                │
│ ○ 免费                              │
│ ● 付费 [$___] 美元                   │
│                                     │
│ □ 我确认拥有此素材的版权            │
│                                     │
│        [取消]  [发布]               │
└─────────────────────────────────────┘
```

### 发布要求

- 必须是原创或有版权
- 标题 2-50 字符
- 至少选择一个分类
- 勾选版权确认

### 审核流程

1. 提交后进入待审核状态
2. 审核通过后上架
3. 审核不通过会收到通知

## 已发布管理

### 状态标识

| 状态 | 显示 |
|------|------|
| 审核中 | 🟡 审核中 |
| 已上架 | 🟢 已发布 |
| 已下架 | ⚫ 已下架 |
| 被拒绝 | 🔴 未通过 |

### 操作

- 查看详情：跳转到市场页面
- 编辑信息：修改标题、描述、价格
- 下架：从市场移除
- 查看销量：销售统计

---

## 收藏/星标

### 功能

- 点击星标收藏素材
- 收藏的素材出现在"收藏"侧边栏

### 在编辑器中使用

- 收藏的素材在编辑器素材面板显示
- 快速访问常用素材
