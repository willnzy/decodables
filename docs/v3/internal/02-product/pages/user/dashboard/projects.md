## 项目列表

### 视图切换

| 视图 | 显示内容 |
|------|----------|
| 网格 | 缩略图、名称、更新时间 |
| 列表 | 缩略图(小)、名称、页数、更新时间、操作 |

### 排序选项

- 最近编辑 (默认)
- 名称 A-Z
- 名称 Z-A
- 创建时间

### 筛选选项

- 全部
- 最近 7 天
- 最近 30 天
- 按文件夹

## 文件夹管理

### 创建文件夹

1. 点击"新建文件夹"
2. 输入名称
3. 选择颜色 (可选)
4. 确认创建

### 文件夹卡片

```
┌─────────────────────┐
│  📁 工作项目        │
│     12 个项目       │
│               [⋮]   │
└─────────────────────┘
```

### 拖放整理

- 拖动项目到文件夹
- 拖动项目出文件夹
- 文件夹间拖动
- 多选后批量移动

---

## 垃圾箱

### 进入垃圾箱

- 侧边栏点击"垃圾箱"
- 显示已删除的项目

### 垃圾箱操作

| 操作 | 说明 |
|------|------|
| 还原 | 恢复到原位置或选择新位置 |
| 永久删除 | 二次确认后彻底删除 |
| 清空垃圾箱 | 删除所有内容 |

### 自动清理

- 30 天后自动永久删除
- 显示剩余天数

---

## 创建项目

### 入口

1. 右上角"+ 新建"按钮
2. 项目列表的"+ 新建"卡片
3. 快捷键 Cmd/Ctrl + N

### 创建方式

| 方式 | 说明 |
|------|------|
| 空白项目 | 选择尺寸后创建 |
| 从模板创建 | 浏览模板库选择 |
| 导入文件 | 上传 PNG/PDF/SVG |
| AI 生成 | 输入描述生成 |

### 尺寸预设

| 名称 | 尺寸 |
|------|------|
| 手机壁纸 | 1080 × 1920 |
| 海报 | 1080 × 1440 |
| 社交媒体 | 1080 × 1080 |
| 横幅 | 1920 × 600 |
| 自定义 | 输入宽高 |
