## 概述

工作区用于隔离个人和团队的项目、素材。支持多工作区切换。

---

## 工作区类型

| 类型 | 说明 | 限制 |
|------|------|------|
| 个人 | 默认工作区，仅自己可见 | 每用户 1 个 |
| 团队 | 多人协作空间 | t3 用户可创建 |

---

## 工作区切换器

```
┌─────────────────────┐
│ 👤 我的工作区    ▼  │
└─────────────────────┘
         ↓ 展开
┌─────────────────────┐
│ ✓ 👤 我的工作区     │
│   👥 设计团队       │
│   👥 客户项目       │
│ ─────────────────── │
│   + 创建团队工作区  │
│   ⚙ 工作区设置      │
└─────────────────────┘
```

## 团队工作区

### 创建团队 (t3 限定)

```
┌─────────────────────────────────────┐
│ 创建团队工作区                       │
├─────────────────────────────────────┤
│ 团队名称 [________________]          │
│                                     │
│ 团队头像 [选择图片]                  │
│                                     │
│        [取消]  [创建]               │
└─────────────────────────────────────┘
```

### 成员角色

| 角色 | 权限 |
|------|------|
| 所有者 | 全部权限，可删除团队 |
| 管理员 | 管理成员、管理项目 |
| 成员 | 编辑项目、上传素材 |
| 访客 | 仅查看 |

## 邀请成员

### 邀请方式

1. **邮箱邀请**：输入邮箱发送邀请链接
2. **链接邀请**：生成邀请链接分享

### 邀请对话框

```
┌─────────────────────────────────────┐
│ 邀请成员加入 "设计团队"             │
├─────────────────────────────────────┤
│ 邮箱 [________________] [+ 添加]    │
│                                     │
│ 已添加:                             │
│   alice@example.com [管理员 ▼] [×]  │
│   bob@example.com   [成员 ▼]   [×]  │
│                                     │
│ ─────────── 或 ───────────         │
│                                     │
│ 分享邀请链接                        │
│ [https://...invite/xxx]  [复制]     │
│ 链接有效期 7 天                     │
│                                     │
│        [取消]  [发送邀请]           │
└─────────────────────────────────────┘
```

## 成员管理

### 成员列表

```
┌─────────────────────────────────────────────────┐
│ 成员 (3)                          [+ 邀请成员]  │
├─────────────────────────────────────────────────┤
│ 👤 张三 (你)      所有者                        │
│ 👤 李四           管理员 ▼        [移除]        │
│ 👤 王五           成员 ▼          [移除]        │
├─────────────────────────────────────────────────┤
│ 待接受邀请                                      │
│ ✉️ alice@...      成员   2 天前   [取消邀请]    │
└─────────────────────────────────────────────────┘
```

### 操作

- 更改角色：下拉选择新角色
- 移除成员：确认后移除
- 取消邀请：撤销未接受的邀请

## 数据隔离

- 每个工作区有独立的项目、素材、文件夹
- 切换工作区后显示对应数据
- 搜索仅在当前工作区范围内
