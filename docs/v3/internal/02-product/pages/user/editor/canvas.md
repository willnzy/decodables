## 概述

---

## 画布交互

### 选择操作

| 操作 | 桌面端 | 移动端 |
|------|--------|--------|
| 单选 | 单击对象 | 点击对象 |
| 多选 | Shift + 点击 | 长按后点击其他 |
| 框选 | 拖动空白区域 | 双指框选 |
| 取消选择 | 点击空白 / Esc | 点击空白区域 |

### 变换操作

| 操作 | 方式 |
|------|------|
| 移动 | 拖动对象 |
| 缩放 | 拖动控制点 / 属性面板输入 |
| 旋转 | 拖动旋转手柄 / 属性面板输入 |
| 等比缩放 | Shift + 拖动控制点 |

---

## 画布导航

### 缩放

| 操作 | 桌面端 | 移动端 |
|------|--------|--------|
| 放大 | Cmd/Ctrl + 滚轮上 | 双指张开 |
| 缩小 | Cmd/Ctrl + 滚轮下 | 双指捏合 |
| 适合窗口 | Cmd/Ctrl + 0 | 双击空白 |
| 100% | Cmd/Ctrl + 1 | - |

### 平移

| 操作 | 桌面端 | 移动端 |
|------|--------|--------|
| 自由平移 | Space + 拖动 | 单指拖动空白 |
| 上下滚动 | 滚轮 | - |
| 左右滚动 | Shift + 滚轮 | - |

---

## 视觉辅助

### 网格

- 可开关 (快捷键 G)
- 网格间距可调 (8/16/32px)
- 对齐到网格可开关

### 标尺

- 顶部和左侧标尺
- 可拖出参考线
- 双击参考线删除

### 智能参考线

- 对象对齐时自动显示
- 边缘对齐、中心对齐
- 等间距提示

## 选中对象反馈

```
┌────────────────────────┐
│  ○────────────────○    │  ← 控制点
│  │                │    │
│  │    Selected    │    │
│  │     Object     │    │
│  │                │    │
│  ○────────────────○    │
└────────────────────────┘
         ↻                    ← 旋转手柄
```

- 选中边框：蓝色 2px
- 控制点：8px 圆形
- 旋转手柄：距离边框 20px
