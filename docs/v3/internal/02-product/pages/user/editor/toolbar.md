## 概述

---

## 顶部导航栏 (Header)

### 桌面端

```
[←返回] [项目名称 ▼] ──空白区── [↶撤销][↷重做] [保存][导出 ▼][分享]
```

| 元素 | 交互 |
|------|------|
| 返回 | 返回 Dashboard，未保存提示 |
| 项目名称 | 点击可编辑，下拉显示版本历史 |
| 撤销/重做 | 快捷键 Cmd+Z / Cmd+Shift+Z |
| 保存 | 手动保存，自动保存也在运行 |
| 导出 | 下拉菜单 (PNG/PDF/SVG) |
| 分享 | 生成分享链接 |

### 移动端

```
[←] [项目名称] ──空白区── [⋮更多]
```

- 简化为返回 + 名称 + 更多菜单
- 更多菜单包含：保存、导出、分享、撤销、重做

## 底部工具栏 (Toolbar)

### 桌面端

```
[🖱选择] [✏绘画 ▼] [T文字 ▼] [⬜形状 ▼] [🖼图片] [✨AI ▼] [⋯更多]
```

| 工具 | 子选项 |
|------|--------|
| 选择 | 框选、单选、多选 |
| 绘画 | 画笔、马克笔、橡皮擦、矢量笔 |
| 文字 | 普通文字、艺术字、曲线文字 |
| 形状 | 矩形、圆形、三角形、线条、箭头 |
| 图片 | 上传、从素材库选择 |
| AI | AI 生图、AI 生页面、OCR |
| 更多 | 表格、二维码、标尺、网格 |

### 移动端

```
[选择] [绘画] [文字] [形状] [+更多]
```

- 精简为 4 个常用 + 更多
- 更多展开为全屏 Sheet

---

## 工具切换交互

1. **单击**：切换到该工具
2. **长按/右键**：展开子工具选项
3. **双击**：使用该工具的上次设置

---

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| V | 选择工具 |
| B | 画笔工具 |
| T | 文字工具 |
| R | 矩形工具 |
| O | 圆形工具 |
| Space + 拖动 | 平移画布 |
