## 概述

编辑器页面的整体布局设计，包括桌面端和移动端的响应式适配。

---

## 桌面端布局 (≥768px)

### 区域划分

| 区域 | 位置 | 宽度 | 说明 |
|------|------|------|------|
| Header | 顶部 | 100% | 64px 高度 |
| Media Panel | 左侧 | 280px | 可折叠 |
| Canvas | 中央 | 自适应 | 核心区域 |
| Properties Panel | 右侧 | 320px | 可折叠 |
| Toolbar | 底部 | 100% | 56px 高度 |

### 面板折叠

- 双击面板边缘折叠
- 折叠后显示图标条 (48px)
- 记住用户偏好 (localStorage)

---

## 移动端布局 (<768px)

### 区域调整

| 区域 | 变化 |
|------|------|
| Header | 简化，仅保留核心按钮 |
| Media Panel | 变为底部 Sheet 抽屉 |
| Canvas | 全屏，支持双指缩放 |
| Properties Panel | 变为底部 Sheet 抽屉 |
| Toolbar | 固定底部，图标精简 |

### 手势操作

- 单指拖动：移动画布
- 双指捏合：缩放画布
- 长按对象：弹出操作菜单

## 响应式断点

```css
/* 移动端 */
@media (max-width: 767px) { ... }

/* 平板 */
@media (min-width: 768px) and (max-width: 1023px) { ... }

/* 桌面 */
@media (min-width: 1024px) { ... }
```
