## 概述

编辑器在移动设备上的特殊适配，优化触摸操作体验。

---

## 布局变化

### 桌面端 vs 移动端

| 区域 | 桌面端 | 移动端 |
|------|--------|--------|
| Header | 完整导航栏 | 精简 3 按钮 |
| Media Panel | 左侧常驻 | 底部 Sheet |
| Canvas | 中央区域 | 全屏 |
| Properties | 右侧常驻 | 底部 Sheet |
| Toolbar | 底部工具条 | 底部浮动 |

---

## 触摸手势

### 画布操作

| 手势 | 操作 |
|------|------|
| 单指点击 | 选中对象 |
| 单指拖动 | 移动选中对象 / 平移画布 |
| 双指捏合 | 缩放画布 |
| 双指旋转 | 旋转选中对象 |
| 长按 | 弹出上下文菜单 |
| 双击 | 进入文字编辑 / 适合窗口 |

### Sheet 操作

| 手势 | 操作 |
|------|------|
| 上滑 | 展开 Sheet |
| 下滑 | 收起 Sheet |
| 点击遮罩 | 关闭 Sheet |

## 属性编辑

### 快捷属性栏

选中对象时，底部显示快捷属性：

```
┌─────────────────────────────────────┐
│ [颜色] [字体] [大小] [对齐] [更多▲] │
└─────────────────────────────────────┘
```

点击"更多"展开完整属性 Sheet。

---

## 键盘处理

### 文字输入

- 自动弹出软键盘
- 画布自动上移避免遮挡
- 完成后恢复位置

### 数字输入

- 属性面板数字输入使用数字键盘
- 支持直接输入 + 步进按钮

---

## Safe Area 处理

```css
/* 底部工具栏 */
padding-bottom: env(safe-area-inset-bottom);

/* 全屏 Sheet */
padding-bottom: calc(16px + env(safe-area-inset-bottom));
```
