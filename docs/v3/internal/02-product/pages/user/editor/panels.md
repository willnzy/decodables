## Media 面板 (左侧)

### 标签页

| Tab | 内容 |
|-----|------|
| 页面 | 当前项目的所有页面缩略图 |
| 素材 | 我的素材 + 素材市场 |
| 模板 | 模板库浏览和搜索 |

### 页面 Tab

```
┌─────────────────────┐
│ 📄 页面 (3/20)      │
├─────────────────────┤
│ ┌─────┐ ┌─────┐    │
│ │ P1  │ │ P2  │    │
│ │ ✓   │ │     │    │
│ └─────┘ └─────┘    │
│ ┌─────┐            │
│ │ P3  │ [+ 新建]   │
│ └─────┘            │
└─────────────────────┘
```

- 拖拽排序页面
- 右键菜单：复制、删除、重命名
- 当前页面高亮显示

### 素材 Tab

## Properties 面板 (右侧)

### 无选中时

显示页面属性：
- 页面尺寸
- 背景颜色
- 背景图片

### 选中对象时

根据对象类型显示不同属性：

#### 通用属性

| 属性 | 控件 |
|------|------|
| 位置 X/Y | 数字输入 |
| 尺寸 W/H | 数字输入 + 锁定比例 |
| 旋转角度 | 数字输入 + 滑块 |
| 透明度 | 滑块 0-100% |
| 混合模式 | 下拉选择 |

#### 文字专属

| 属性 | 控件 |
|------|------|
| 字体 | 字体选择器 |
| 字号 | 数字输入 |
| 字重 | 下拉选择 |
| 颜色 | 颜色选择器 |
| 对齐 | 按钮组 |
| 行高 | 数字输入 |
| 字间距 | 数字输入 |

#### 形状专属

| 属性 | 控件 |
|------|------|
| 填充色 | 颜色选择器 |
| 边框色 | 颜色选择器 |
| 边框宽度 | 数字输入 |
| 圆角 | 数字输入 |

#### 图片专属

| 属性 | 控件 |
|------|------|
| 裁切 | 裁切按钮 |
| 滤镜 | 滤镜选择器 |
| 翻转 | 水平/垂直按钮 |

## 图层面板 (Properties 底部)

```
┌─────────────────────┐
│ 📚 图层             │
├─────────────────────┤
│ [👁] 文字 "Hello"   │
│ [👁] 矩形           │
│ [👁] 图片           │  ← 可拖拽排序
│ [👁] 背景           │
└─────────────────────┘
```

- 点击选中图层对应对象
- 拖拽调整层级
- 眼睛图标切换可见性
- 右键菜单：锁定、删除、复制

---

## 移动端适配

- 面板变为底部 Sheet 抽屉
- 点击工具栏图标展开
- 下滑关闭
