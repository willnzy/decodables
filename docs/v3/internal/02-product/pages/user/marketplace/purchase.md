## 快速预览 Modal

### 触发方式

- 点击商品卡片的"预览"按钮
- 点击商品卡片 (非收藏按钮区域)

### Modal 布局

```
┌───────────────────────────────────────────────────┐
│                                               [×] │
│ ┌─────────────────────┐  商品名称                │
│ │                     │  👤 卖家名              │
│ │    [大图预览]        │  ⭐ 4.8 (123 评价)      │
│ │                     │                         │
│ │                     │  ─────────────────────  │
│ │                     │  这是商品描述...         │
│ │                     │                         │
│ └─────────────────────┘  标签: [设计] [模板]    │
│ [◀ 上一张] 1/5 [下一张 ▶]                       │
│                                                  │
│ ┌─────────────────────────────────────────────┐ │
│ │ 🆓 免费  或  $9.99                          │ │
│ │                                              │ │
│ │ [❤️ 收藏]           [获取] / [购买]          │ │
│ └─────────────────────────────────────────────┘ │
└───────────────────────────────────────────────────┘
```

### 预览图

- 支持多张预览图轮播
- 点击图片放大全屏
- 箭头或滑动切换

## 购买流程

### 免费商品

```
点击"获取" → 直接添加到我的素材 → 显示成功提示
```

### 付费商品 (积分支付)

```
点击"购买" → 确认对话框 → 扣除积分 → 添加到我的素材 → 成功提示
```

### 购买确认 Modal

```
┌─────────────────────────────────────┐
│ 确认购买                            │
├─────────────────────────────────────┤
│ 商品: 夏日插画包                    │
│ 价格: $9.99 (100 积分)              │
│                                     │
│ 当前积分: 250                       │
│ 购买后剩余: 150                     │
│                                     │
│        [取消]  [确认购买]           │
└─────────────────────────────────────┘
```

### 积分不足

```
┌─────────────────────────────────────┐
│ 积分不足                            │
├─────────────────────────────────────┤
│ 商品: 夏日插画包                    │
│ 需要: 100 积分                      │
│ 当前: 50 积分                       │
│ 还需: 50 积分                       │
│                                     │
│ [取消]  [充值积分]                  │
└─────────────────────────────────────┘
```

## 购买成功

### 成功提示

```
┌─────────────────────────────────────┐
│ ✅ 购买成功!                        │
├─────────────────────────────────────┤
│ 夏日插画包 已添加到你的素材库       │
│                                     │
│ [继续浏览]  [去使用]                │
└─────────────────────────────────────┘
```

### 后续引导

- "继续浏览"：关闭 Modal，留在 Marketplace
- "去使用"：跳转到 Dashboard 素材页

## 收藏功能

### 收藏操作

- 点击 ❤️ 按钮切换收藏状态
- 需要登录才能收藏
- 未登录点击弹出登录提示

### 收藏列表

- 收藏的商品在 Dashboard "收藏" 中显示
- 可以从收藏列表快速购买

---

## 已购买状态

### 卡片显示

```
┌─────────────────────┐
│                     │
│   [商品预览图]       │
│        ✅ 已购买    │
│                     │
├─────────────────────┤
│ 商品名称            │
│ [再次下载]          │
└─────────────────────┘
```

### 操作

- 显示"已购买"标识
- 按钮变为"再次下载"
- 不显示价格
