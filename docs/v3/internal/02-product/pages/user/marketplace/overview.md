## 概述

Marketplace 页面的整体布局设计，包括筛选侧边栏和商品展示区。

---

## 桌面端布局 (≥768px)

### 区域划分

| 区域 | 位置 | 尺寸 | 说明 |
|------|------|------|------|
| Header | 顶部 | 64px 高 | 全局导航 |
| Filter Sidebar | 左侧 | 240px 宽 | 筛选条件 |
| Tab Bar | 内容顶部 | 48px 高 | 热门/最新/免费/付费 |
| Listings Grid | 中央 | 自适应 | 商品瀑布流 |
| Leaderboard | 右侧 | 280px 宽 | 可选，销量排行榜 |

### 布局示意

```
┌─────────────────────────────────────────────────────┐
│                     Header                          │
├──────────┬─────────────────────────────┬────────────┤
│          │ [热门] [最新] [免费] [付费]  │            │
│  Filter  ├─────────────────────────────┤ Leaderboard│
│  Sidebar │                             │            │
│          │     Listings Grid           │  Top 10    │
│          │                             │  Sellers   │
│          │                             │            │
└──────────┴─────────────────────────────┴────────────┘
```

---

## 移动端布局 (<768px)

### 区域变化

| 区域 | 变化 |
|------|------|
| Header | 简化，搜索图标化 |
| Filter Sidebar | 变为筛选按钮 + Sheet |
| Tab Bar | 横向滚动 |
| Listings Grid | 2 列网格 |
| Leaderboard | 移到顶部横向滚动 |

## 商品网格

### 响应式列数

| 断点 | 列数 |
|------|------|
| <640px | 2 列 |
| 640-1023px | 3 列 |
| ≥1024px | 4 列 |

### 虚拟列表

- 使用虚拟滚动优化性能
- 只渲染可视区域 + 缓冲区
- 滚动加载更多
