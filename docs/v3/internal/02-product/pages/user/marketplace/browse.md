## 概述

---

## Tab 导航

### Tab 选项

| Tab | 内容 | 排序 |
|-----|------|------|
| 热门 | 高销量商品 | 按销量降序 |
| 最新 | 最近上架 | 按上架时间降序 |
| 免费 | 免费商品 | 按下载量降序 |
| 付费 | 付费商品 | 按销量降序 |

### 交互

- 点击切换 Tab
- URL 同步 `?tab=hot`
- 保留筛选条件

---

## 筛选系统

### 筛选维度

| 维度 | 类型 | 选项 |
|------|------|------|
| 分类 | 多选 | 模板/素材包/图标/字体 |
| 价格 | 单选 | 全部/免费/$1-5/$5-10/$10+ |
| 颜色 | 多选 | 12 种主要颜色 |
| 风格 | 多选 | 扁平/3D/手绘/极简/复古 |

### 筛选逻辑

- 分类：OR 关系 (选中任一即匹配)
- 价格：单选互斥
- 颜色：OR 关系
- 风格：OR 关系
- 跨维度：AND 关系

### 已选筛选标签

```
┌─────────────────────────────────────────────────┐
│ [模板 ×] [免费 ×] [扁平 ×]      [清除全部]      │
└─────────────────────────────────────────────────┘
```

- 显示当前已选筛选
- 点击 × 移除单个
- 点击"清除全部"重置

## 商品卡片

### 卡片设计

```
┌─────────────────────┐
│                     │
│   [商品预览图]       │
│                     │
│ [❤️ 收藏]     [👁 预览]│
├─────────────────────┤
│ 商品名称            │
│ 👤 卖家名           │

```

### 悬停效果

- 显示收藏和预览按钮
- 轻微放大 (scale: 1.02)
- 阴影加深

### 价格显示

| 类型 | 显示 |
|------|------|
| 免费 | 🆓 免费 |
| 付费 | $9.99 |
| 折扣 | ~~$12.99~~ $9.99 |

## 排序

### 排序选项

| 选项 | 说明 |
|------|------|
| 推荐 | 算法推荐 (默认) |
| 最新 | 按上架时间 |
| 销量 | 按销售数量 |
| 价格低到高 | 价格升序 |
| 价格高到低 | 价格降序 |
| 评分 | 按评分降序 |

### 排序入口

```
[排序: 推荐 ▼]
```

## 分页与加载

### 加载方式

- **桌面端**：无限滚动 + "加载更多"按钮
- **移动端**：无限滚动自动加载

### 加载状态

```
┌────┐ ┌────┐ ┌────┐ ┌────┐
│ ░░ │ │ ░░ │ │ ░░ │ │ ░░ │  ← 骨架屏
└────┘ └────┘ └────┘ └────┘

     [加载中...]
```

### 空状态
