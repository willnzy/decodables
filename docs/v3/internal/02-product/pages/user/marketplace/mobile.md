## 概述

Marketplace 在移动设备上的特殊适配，优化触摸浏览和购买体验。

---

## 布局变化

### 桌面端 vs 移动端

| 区域 | 桌面端 | 移动端 |
|------|--------|--------|
| 筛选侧边栏 | 左侧常驻 | 筛选按钮 + Sheet |
| Tab 导航 | 固定 | 横向滚动 |
| 商品网格 | 4 列 | 2 列 |
| 排行榜 | 右侧 | 顶部横向滚动 |
| 搜索框 | 展开 | 图标，点击展开 |

---

## 筛选 Sheet

### 触发

- 点击"筛选"按钮
- 从底部滑出

### Sheet 内容

```
┌─────────────────────────────────────┐
│ 筛选                          [×]  │
├─────────────────────────────────────┤
│ 分类                               │
│ [模板] [素材包] [图标] [字体]      │
│                                     │
│ 价格                               │
│ [全部] [免费] [$1-5] [$5-10] [$10+]│
│                                     │
│ 颜色                               │
│ [🔴][🟠][🟡][🟢][🔵][🟣][⚫][⚪]  │
│                                     │
│ 风格                               │
│ [扁平] [3D] [手绘] [极简]          │
├─────────────────────────────────────┤
│ [重置]              [应用筛选]     │
└─────────────────────────────────────┘
```

### 交互

- 下滑关闭
- 点击遮罩关闭
- "应用筛选"确认并关闭

## 触摸优化

### 触摸目标

- 卡片点击区域 ≥ 44px
- 按钮高度 ≥ 44px
- 筛选标签 ≥ 36px

### 反馈效果

- 点击卡片：scale(0.98) + 浅色背景
- 点击按钮：scale(0.95)
