## 一、概述

### 1.1 功能定位

通知系统用于向用户传达重要信息，包括系统公告、订阅状态和活动提醒。

### 1.2 通知类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 系统通知 | 平台公告、维护通知 | "Scheduled maintenance" |
| 订阅通知 | 订阅状态变化 | "Subscription renewed" |
| 积分通知 | 积分变动提醒 | "Monthly credits granted" |
| 活动通知 | 促销、活动提醒 | "50% off this week" |

## 四、通知触发

### 4.1 系统触发

| 事件 | 通知内容 |
|------|----------|
| 注册成功 | 欢迎消息 + 积分赠送 |
| 订阅成功 | 确认 + 权益说明 |
| 订阅续期 | 续期确认 + 积分发放 |
| 订阅取消 | 确认 + 到期日期 |
| 积分发放 | 发放数量 + 当前余额 |
| 积分不足 | 余额提醒 + 充值入口 |

### 4.2 管理员触发

| 场景 | 说明 |
|------|------|
| 系统公告 | 全站通知 |
| 维护通知 | 计划维护时间 |
| 活动通知 | 促销活动 |

## 五、通知设置 (计划)

### 5.1 设置选项

| 设置 | 默认 | 说明 |
|------|------|------|
| 系统通知 | ✅ 开 | 不可关闭 |
| 订阅通知 | ✅ 开 | 付款相关 |
| 活动通知 | ✅ 开 | 可关闭 |
| 邮件通知 | ✅ 开 | 重要通知邮件 |

## 六、API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/notifications` | GET | 获取通知列表 |
| `/notifications/unread-count` | GET | 获取未读数量 |
| `/notifications/{id}/read` | POST | 标记已读 |
| `/notifications/read-all` | POST | 全部标记已读 |
