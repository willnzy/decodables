## 一、概述

### 1.1 功能定位

编辑器是 Make Decodables 的核心功能，用于创建和编辑 8 页 Mini-book 教育内容。

### 1.2 目标用户

- K-2 教师 (主要)
- 家长
- 教育内容创作者

### 1.3 核心价值

- 简单易用 (5 分钟创建一本书)
- 教育专业 (Phonics 模板、Sight Words)
- AI 辅助 (智能生图、OCR)

## 二、功能范围

### 2.1 功能清单

| 模块 | 功能 | 优先级 |
|------|------|--------|

- 多人实时协作 (V2)

## 四、功能详情

### 4.1 Canvas 操作

#### 4.1.1 多页管理

```
┌─────────────────────────────────────────────────────┐
│                 8 页 Mini-book 结构                  │
├─────────────────────────────────────────────────────┤
│                                                     │
│  Page 1: Cover (封面)                               │
│  Page 2-7: Content (内容页)                         │
│  Page 8: Back Cover (封底)                          │
│                                                     │
│  左侧缩略图列表:                                     │
│  ┌─────┐                                            │
│  │  1  │ ← 当前页高亮                               │
│  ├─────┤                                            │
│  │  2  │                                            │
│  ├─────┤                                            │
│  │ ... │                                            │
│  ├─────┤                                            │
│  │  8  │                                            │
│  └─────┘                                            │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**操作**:
- 点击缩略图切换页面
- 拖拽缩略图调整顺序 (2-7 页)
- 右键菜单: 复制页面、清空页面

#### 4.1.2 缩放与平移

| 操作 | 方式 |
|------|------|
| 缩放 | 滚轮 / 双指捏合 / 工具栏滑块 |
| 平移 | 空格+拖拽 / 双指滑动 |
| 适应屏幕 | 双击空白处 / 快捷键 0 |
| 实际大小 | 快捷键 1 |

**缩放范围**: 10% - 400%

#### 4.1.3 对齐与网格

| 功能 | 说明 |
|------|------|
| 智能参考线 | 移动时显示对齐辅助线 |
| 网格显示 | 可开关，默认关闭 |
| 吸附对齐 | 边缘/中心自动吸附 |
| 等间距分布 | 选中多个对象后可用 |

### 4.5 AI 功能

#### 4.5.1 AI 生图

**流程**:
```
用户输入描述 → 检查积分 → 生成图片 → 添加到画布
```

**参数**:
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 尺寸 | landscape_4_3 | 横向/方形/纵向 |
| 数量 | 1 | 1-4 张 |
| 风格 | children_book | 儿童书插图风格 |

**消耗**: 5 积分/次

#### 4.5.2 AI 生成页面

**功能**: 根据主题自动生成完整页面布局

**流程**:
```
选择主题 → 输入关键词 → AI 生成布局+内容 → 用户调整
```

**消耗**: 5 积分/页

#### 4.5.3 OCR 识别

**功能**: 从图片提取文字

**流程**:
```
上传/选择图片 → OCR 识别 → 转换为可编辑文字
```

**消耗**: 10 积分/次

## 六、技术约束
