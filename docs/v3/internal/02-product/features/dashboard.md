## 一、概述

### 1.1 功能定位

Dashboard 是用户登录后的主页，用于管理项目、查看统计和快速访问常用功能。

### 1.2 核心价值

- 一站式项目管理
- 快速创建入口
- 使用情况概览

## 三、用户故事

| ID | 用户故事 | 验收标准 |
|----|----------|----------|
| DASH-01 | 查看我的项目列表 | 显示所有项目，支持排序 |
| DASH-02 | 创建新项目 | 点击创建，选择模板或空白 |
| DASH-03 | 组织项目到文件夹 | 可创建文件夹，拖拽移动 |
| DASH-04 | 搜索项目 | 按名称搜索，实时过滤 |
| DASH-05 | 批量删除项目 | 多选后批量删除 |

### 4.2 项目卡片

```
┌─────────────────────┐
│  ┌───────────────┐  │
│  │   Thumbnail   │  │
│  │               │  │
│  └───────────────┘  │
│  Project Name       │
│  Edited 2 hours ago │
│  [⋮]                │
└─────────────────────┘
```

**操作菜单** (⋮):
- Open (打开)
- Rename (重命名)
- Duplicate (复制)
- Move to folder (移动)
- Delete (删除)

### 4.3 文件夹管理

| 操作 | 说明 |
|------|------|
| 创建文件夹 | 点击 "+ New Folder" |
| 重命名 | 右键 > Rename |
| 删除 | 右键 > Delete (项目移至根目录) |
| 拖拽移动 | 将项目拖到文件夹 |

### 4.4 搜索筛选

| 筛选项 | 选项 |
|--------|------|
| 排序 | 最近编辑 / 名称 / 创建时间 |
| 视图 | 网格 / 列表 |
| 时间 | 全部 / 今天 / 本周 / 本月 |

## 五、API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/projects` | GET | 获取项目列表 |
| `/projects` | POST | 创建项目 |
| `/projects/{id}` | DELETE | 删除项目 |
| `/folders` | GET | 获取文件夹 |
| `/folders` | POST | 创建文件夹 |
