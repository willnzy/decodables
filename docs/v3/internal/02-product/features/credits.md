## 一、概述

### 1.1 功能定位

积分是 AI 功能的消费货币，用于控制 AI 生图、OCR 等功能的使用量。

### 1.2 积分类型

| 类型 | 来源 | 有效期 |
|------|------|--------|
| **月度积分** | 订阅会员每月发放 | 每月重置 |
| **永久积分** | 注册赠送 / 充值购买 | 永久有效 |

## 五、业务规则

### 5.1 扣费顺序

```
扣费优先级: 月度积分 → 永久积分

示例:
- 用户有: 月度 30, 永久 100
- 消耗 50 积分
- 结果: 月度 0, 永久 80
```

### 5.2 月度积分规则

| 规则 | 说明 |
|------|------|
| 发放时机 | 订阅续期时发放 |
| 重置机制 | 新周期开始时清零旧的，发放新的 |
| 不累积 | 未使用的不累积到下月 |

### 5.3 永久积分规则

| 规则 | 说明 |
|------|------|
| 有效期 | 永久有效 |
| 来源 | 注册赠送 / 充值购买 |
| 无上限 | 可无限累积 |

### 5.4 注册赠送

| 用户类型 | 赠送积分 |
|----------|----------|
| 新注册用户 | 100 永久积分 |

## 七、API 端点

### 7.1 积分查询

| 端点 | 方法 | 说明 |
|------|------|------|
| `/billing/credits` | GET | 获取积分余额 |

**响应**:
```json
{
  "monthly": 45,
  "permanent": 200,
  "total": 245,
  "period_end": "2026-03-01T00:00:00Z"
}
```

### 7.2 交易历史

| 端点 | 方法 | 说明 |
|------|------|------|
| `/billing/transactions` | GET | 获取交易历史 |

**参数**:
| 参数 | 类型 | 说明 |
|------|------|------|
| limit | int | 每页数量 (默认 20) |
| offset | int | 偏移量 |
| type | string | 筛选类型 |

### 7.3 积分充值

| 端点 | 方法 | 说明 |
|------|------|------|
| `/payment/checkout` | POST | 创建充值 Session |

**请求**:
```json
{
  "plan_type": "credits_500"
}
```
