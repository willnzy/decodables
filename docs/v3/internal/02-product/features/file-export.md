# 文件导出功能规格

> **同步范围**: [fullstack]
> **状态**: 🟢 已验证
> **版本**: 1.0.0
> **最后更新**: 2026-02-05
> **数据来源**: `api/user/export.py`

---

## 一、概述

### 1.1 功能定位

导出功能让用户将作品保存为可分享和打印的文件格式。

### 1.2 支持格式

| 格式 | 用途 | Tier 限制 |
|------|------|-----------|
| PNG | 网络分享、演示 | 全部 |
| JPG | 网络分享、邮件 | 全部 |
| PDF | 打印、分发 | 全部 |

---

## 二、功能范围

| 功能 | 优先级 | 状态 |
|------|--------|------|
| PNG 导出 | P0 | ✅ |
| JPG 导出 | P0 | ✅ |
| PDF 导出 | P0 | ✅ |
| 批量导出 | P1 | ✅ |
| 高清导出 | P1 | ✅ |

---

## 三、PNG/JPG 导出

### 3.1 导出选项

| 选项 | 值 | 说明 |
|------|-----|------|
| 格式 | PNG / JPG | PNG 支持透明 |
| 页面 | 当前页 / 全部 | 全部导出为 ZIP |
| 分辨率 | 72/150/300 DPI | 高清需 t2+ |
| 质量 | 80-100% | 仅 JPG |

### 3.2 导出界面

```
┌────────────────────────────────────────────────────────────┐
│  Export as Image                                           │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  Format: [PNG ▼]                                           │
│                                                            │
│  Pages:  ○ Current page                                    │
│          ● All pages (as ZIP)                              │
│                                                            │
│  Quality: [300 DPI ▼]    ⭐ HD export (Starter+)           │
│                                                            │
│  [Cancel]                              [Download]          │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

---

## 四、PDF 导出

### 4.1 导出选项

| 选项 | 值 | 说明 |
|------|-----|------|
| 页面 | 全部 / 选定 | 选择导出范围 |
| 尺寸 | Letter / A4 | 纸张大小 |
| 质量 | 屏幕/打印/高质量 | 压缩级别 |
| 布局 | 单页/双页 | 打印布局 |

### 4.2 质量选项

| 质量 | 分辨率 | 文件大小 | 用途 |
|------|--------|----------|------|
| 屏幕 | 72 DPI | 小 | 预览 |
| 打印 | 150 DPI | 中 | 普通打印 |
| 高质量 | 300 DPI | 大 | 高清打印 |

## 七、API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/export/image` | POST | 导出图片 |
| `/export/pdf` | POST | 导出 PDF |

### 7.1 请求示例

```json
// POST /export/image
{
  "project_id": "uuid",
  "format": "png",
  "pages": "all",
  "dpi": 300
}
```

### 7.2 响应

```json
{
  "download_url": "https://...",
  "expires_at": "2026-02-05T12:00:00Z"
}
```
