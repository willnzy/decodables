# 文件导入功能规格

> **同步范围**: [fullstack]
> **状态**: 🟢 已验证
> **版本**: 1.0.0
> **最后更新**: 2026-02-05
> **数据来源**: `v2/04-features/file-import-support.md`

## 一、概述

### 1.1 功能定位

支持用户导入现有文件到编辑器，方便复用已有内容。

### 1.2 支持格式

| 格式 | 支持程度 | 说明 |
|------|----------|------|
| PNG | ✅ 完整 | 作为图片导入 |
| JPG/JPEG | ✅ 完整 | 作为图片导入 |
| GIF | ✅ 完整 | 作为图片导入 |
| SVG | ✅ 完整 | 作为矢量图或图片 |
| PDF | 🟡 部分 | 转换为图片 |
| WEBP | ✅ 完整 | 作为图片导入 |

| PDF 导入 | P1 | 🟡 |
| 拖拽导入 | P1 | ✅ |
| 批量导入 | P2 | ✅ |

## 三、图片导入

### 3.1 导入方式

| 方式 | 说明 |
|------|------|
| 点击上传 | 点击上传按钮选择文件 |
| 拖拽 | 直接拖拽到画布 |
| 粘贴 | Ctrl+V 粘贴剪贴板图片 |

### 3.2 文件限制

| 限制 | 值 |
|------|-----|
| 单文件大小 | 最大 10 MB |
| 批量上传 | 最多 10 个 |
| 图片尺寸 | 最大 8000x8000 px |

### 3.3 导入流程

```
选择文件 → 验证格式/大小 → 上传到存储 → 添加到画布
```

---

## 四、SVG 导入

### 4.1 导入模式

| 模式 | 说明 |
|------|------|
| 作为图片 | 保持原样，不可编辑路径 |
| 作为矢量 | 转换为可编辑的路径对象 |

### 4.2 支持的 SVG 元素

| 元素 | 支持 |
|------|------|
| `<path>` | ✅ |
| `<rect>` | ✅ |
| `<circle>` | ✅ |
| `<ellipse>` | ✅ |
| `<line>` | ✅ |
| `<polygon>` | ✅ |
| `<text>` | 🟡 转为图片 |

---

## 五、PDF 导入

### 5.1 导入流程

```
上传 PDF → 选择页面 → 转换为图片 → 添加到画布
```

### 5.2 转换选项

| 选项 | 说明 |
|------|------|
| 分辨率 | 72/150/300 DPI |
| 页面范围 | 全部/指定页 |
| 格式 | PNG (默认) |

### 5.3 限制

| 限制 | 值 |
|------|-----|
| 文件大小 | 最大 20 MB |
| 页数 | 最多 50 页 |

---

## 六、错误处理

| 错误 | 用户提示 |
|------|----------|
| 格式不支持 | "This file format is not supported" |
| 文件过大 | "File size exceeds 10 MB limit" |
| 尺寸过大 | "Image dimensions exceed limit" |
| 上传失败 | "Upload failed. Please try again" |

---

## 七、API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/uploads/image` | POST | 上传图片 |
| `/uploads/svg` | POST | 上传 SVG |
| `/uploads/pdf` | POST | 上传 PDF |
