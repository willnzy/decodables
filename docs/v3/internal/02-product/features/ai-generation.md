## 一、概述

### 1.1 功能定位

AI 生成功能帮助用户快速创建高质量的教育内容插图和布局。

### 1.2 AI 功能列表

| 功能 | 消耗积分 | 说明 |
|------|----------|------|
| AI 生图 | 5 | 根据描述生成图片 |
| AI 生成页面 | 5 | 自动生成页面布局 |
| OCR 识别 | 10 | 从图片提取文字 |

## 三、AI 图片生成

### 3.1 用户流程

```
输入描述 → 选择参数 → 检查积分 → 生成图片 → 添加到画布
```

### 3.2 生成界面

```
┌────────────────────────────────────────────────────────────┐
│  AI Image Generation                                       │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  Describe what you want to create:                         │
│  ┌──────────────────────────────────────────────────────┐ │
│  │ A happy cat sitting on a colorful mat, children's    │ │
│  │ book illustration style                              │ │
│  └──────────────────────────────────────────────────────┘ │
│                                                            │
│  Size: [Landscape ▼]     Images: [1 ▼]                    │
│                                                            │
│  ⚡ This will use 5 credits (You have 245)                │
│                                                            │
│  [Cancel]                              [Generate]          │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 3.3 参数说明

| 参数 | 选项 | 说明 |
|------|------|------|
| Size | Landscape / Square / Portrait | 图片方向 |
| Images | 1-4 | 生成数量 (t3 用户最多 4 张) |
| Style | Auto | 自动优化为儿童书风格 |

### 3.4 提示词技巧

| 技巧 | 示例 |
|------|------|
| 描述主体 | "A happy cat" |
| 添加环境 | "sitting on a red mat" |
| 指定风格 | "children's book illustration" |
| 避免复杂 | 简单场景效果更好 |

## 四、AI 页面生成

### 4.1 用户流程

```
选择主题 → 输入关键词 → 生成布局 → 编辑调整
```

### 4.2 生成界面

```
┌────────────────────────────────────────────────────────────┐
│  AI Page Generation                                        │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  Theme: [Phonics - CVC Words ▼]                           │
│                                                            │
│  Keywords: [cat, mat, sat, hat]                           │
│                                                            │
│  ⚡ This will use 5 credits                               │
│                                                            │
│  [Cancel]                              [Generate]          │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 4.3 支持的主题

| 主题 | 说明 |
|------|------|
| Phonics - CVC | 自然拼读 CVC 单词 |
| Phonics - Blends | 辅音组合 |
| Sight Words | 高频词 |
| Story | 故事页面 |

---

## 五、OCR 文字识别

### 5.1 用户流程

```
选择图片 → 识别文字 → 转为可编辑文本 → 添加到画布
```

### 5.2 支持的图片类型

| 类型 | 说明 |
|------|------|
| 手写文字 | 清晰的手写内容 |
| 印刷文字 | 书籍、文档 |
| 截图 | 屏幕截图中的文字 |

### 5.3 消耗积分

10 积分/次

---

## 六、积分消耗规则

| 场景 | 消耗 | 说明 |
|------|------|------|
| 生成成功 | 正常扣除 | 生成完成后扣除 |
| 生成失败 | 不扣除 | 系统错误不扣积分 |
| 内容违规 | 扣除 | 用户输入违规内容 |

---

## 七、API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/generations/image` | POST | 生成图片 |
| `/generations/page` | POST | 生成页面 |
| `/generations/ocr` | POST | OCR 识别 |
| `/generations/history` | GET | 生成历史 |
