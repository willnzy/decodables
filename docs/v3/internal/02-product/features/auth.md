> **同步范围**: [fullstack]
> **状态**: 🟢 已验证

> **最后更新**: 2026-02-05

## 一、概述

### 1.1 功能定位

认证模块负责用户身份验证和会话管理，采用自建认证系统 (非第三方 OAuth)。

### 1.2 认证方式

| 方式 | 说明 | 状态 |
|------|------|------|
| Email + OTP | 邮箱 + 一次性密码 | ✅ 已实现 |
| Email + Password | 邮箱 + 密码 | ✅ 已实现 |
| Google OAuth | Google 登录 | 🔜 计划中 |

## 三、用户故事

### 3.1 注册

| ID | 用户故事 | 验收标准 |
|----|----------|----------|
| AUTH-01 | 作为新用户，我想注册账号 | 输入邮箱 → 收到 OTP → 设置密码 → 完成注册 |
| AUTH-02 | 作为新用户，注册后我想自动登录 | 注册成功后直接进入应用 |
| AUTH-03 | 作为新用户，我想获得欢迎积分 | 注册成功后获得 100 永久积分 |

### 3.2 登录

| ID | 用户故事 | 验收标准 |
|----|----------|----------|
| AUTH-04 | 作为用户，我想登录账号 | 输入邮箱密码 → 验证成功 → 进入应用 |
| AUTH-05 | 作为用户，我想在多设备登录 | 最多 5 个设备同时登录 |
| AUTH-06 | 作为用户，登录失败时我想知道原因 | 显示友好错误提示 |

### 3.3 密码管理

| ID | 用户故事 | 验收标准 |
|----|----------|----------|
| AUTH-07 | 作为用户，我想找回密码 | 输入邮箱 → 收到 OTP → 设置新密码 |
| AUTH-08 | 作为用户，我想修改密码 | 输入旧密码 + 新密码 → 验证成功 → 更新密码 |

### 3.4 会话管理

| ID | 用户故事 | 验收标准 |
|----|----------|----------|
| AUTH-09 | 作为用户，我想查看登录设备 | 显示所有活跃会话列表 |
| AUTH-10 | 作为用户，我想登出其他设备 | 可单独撤销指定会话 |
| AUTH-11 | 作为用户，我想登出所有设备 | 一键撤销所有会话 |

## 五、安全要求

### 5.1 密码策略

| 要求 | 值 |
|------|-----|
| 最小长度 | 8 字符 |
| 复杂度 | 字母 + 数字 |
| 加密算法 | Argon2id |

### 5.2 OTP 策略

| 配置 | 值 |
|------|-----|
| OTP 长度 | 6 位数字 |
| 有效期 | 5 分钟 |
| 冷却时间 | 60 秒 |
| 最大尝试 | 5 次 |

### 5.3 登录保护

| 配置 | 值 |
|------|-----|
| 最大失败次数 | 5 次 |
| 锁定时间 | 15 分钟 |
| 最大活跃会话 | 5 个 |

### 5.4 Token 安全

| 配置 | 值 |
|------|-----|
| Access Token 有效期 | 15 分钟 |
| Refresh Token 有效期 | 7 天 |
| Token 算法 | JWT HS256 |
| Refresh Token 存储 | SHA-256 哈希 |

### 5.5 邮箱安全

| 措施 | 说明 |
|------|------|
| 一次性邮箱拦截 | 屏蔽 mailinator 等 |
| 邮箱格式验证 | 严格 RFC 5322 |
| 大小写规范化 | 统一转小写 |

## 七、API 端点

### 7.1 注册

| 端点 | 方法 | 说明 |
|------|------|------|
| `/auth/register/send-otp` | POST | 发送注册 OTP |
| `/auth/register/verify-otp` | POST | 验证 OTP |
| `/auth/register/complete` | POST | 完成注册 |

### 7.2 登录/登出

| 端点 | 方法 | 说明 |
|------|------|------|
| `/auth/login` | POST | 登录 |
| `/auth/refresh` | POST | 刷新 Token |
| `/auth/logout` | POST | 登出当前设备 |
| `/auth/logout-all` | POST | 登出所有设备 |

### 7.3 密码管理

| 端点 | 方法 | 说明 |
|------|------|------|
| `/auth/forgot-password/send-otp` | POST | 发送重置 OTP |
| `/auth/forgot-password/verify-otp` | POST | 验证 OTP |
| `/auth/forgot-password/reset` | POST | 设置新密码 |
| `/auth/change-password` | POST | 修改密码 |

### 7.4 会话管理

| 端点 | 方法 | 说明 |
|------|------|------|
| `/auth/sessions` | GET | 获取所有会话 |
| `/auth/sessions/{id}` | DELETE | 撤销指定会话 |

## 八、验收标准

### 8.1 功能验收

| 功能 | 验收标准 |
|------|----------|
| 注册 | 完成 3 步后能登录 |
| 登录 | 正确凭据能获取 Token |
| 找回密码 | 能通过 OTP 重置密码 |
| 会话管理 | 能查看和撤销会话 |

### 8.2 安全验收

| 项目 | 验收标准 |
|------|----------|
| 密码存储 | 使用 Argon2id 哈希 |
| Token 安全 | Refresh Token 哈希存储 |
| 锁定机制 | 5 次失败后锁定 |
| OTP 安全 | 5 分钟过期 + 5 次尝试限制 |
