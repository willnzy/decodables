## 四、头像管理

### 4.1 上传头像

1. 点击头像或 "Edit" 按钮
2. 选择图片文件
3. 裁切调整
4. 保存

### 4.2 头像要求

| 要求 | 值 |
|------|-----|
| 格式 | PNG, JPG |
| 大小 | 最大 5MB |
| 尺寸 | 自动裁切为正方形 |

## 六、账户删除

### 6.1 删除流程

1. 点击 "Delete Account"
2. 输入密码确认
3. 发送 OTP 到邮箱
4. 验证 OTP
5. 账户软删除

### 6.2 恢复期

- 30 天恢复期
- 期间可登录恢复
- 超期永久删除

## 七、API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/user/profile` | GET | 获取个人信息 |
| `/user/profile` | PATCH | 更新个人信息 |
| `/user/avatar` | POST | 上传头像 |
| `/auth/change-password` | POST | 修改密码 |
| `/auth/delete-account/*` | POST | 删除账户 |
