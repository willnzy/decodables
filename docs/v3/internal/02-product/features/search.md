## 四、筛选和排序

### 4.1 筛选选项

| 筛选 | 选项 |
|------|------|
| 类型 | 项目 / 模板 / 素材 |
| 分类 | 按素材分类筛选 |
| 日期 | 最近 7 天 / 30 天 / 全部 |

### 4.2 排序选项

| 排序 | 说明 |
|------|------|
| 相关度 | 默认，按匹配度排序 |
| 最新 | 按创建/更新时间 |
| 热门 | 按使用量排序 |

---

## 五、搜索逻辑

### 5.1 匹配规则

| 字段 | 权重 | 说明 |
|------|------|------|
| 名称 | 高 | 标题完全匹配 |
| 标签 | 中 | 标签匹配 |
| 描述 | 低 | 描述包含 |

### 5.2 模糊匹配

使用 PostgreSQL `pg_trgm` 扩展支持模糊匹配：

```sql
SELECT * FROM templates
WHERE name % 'animel'  -- 匹配 "animal"
ORDER BY similarity(name, 'animel') DESC;
```

## 六、API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/search` | GET | 全局搜索 |
| `/search/projects` | GET | 搜索项目 |
| `/search/templates` | GET | 搜索模板 |
| `/search/assets` | GET | 搜索素材 |

### 6.1 请求参数

| 参数 | 类型 | 说明 |
|------|------|------|
| q | string | 搜索关键词 |
| type | string | 类型筛选 |
| category | string | 分类筛选 |
| sort | string | 排序方式 |
| limit | int | 每页数量 |
| offset | int | 偏移量 |

### 6.2 响应示例

```json
{
  "query": "animal",
  "total": 60,
  "results": {
    "projects": { "items": [...], "total": 3 },
    "templates": { "items": [...], "total": 12 },
    "assets": { "items": [...], "total": 45 }
  }
}
```
