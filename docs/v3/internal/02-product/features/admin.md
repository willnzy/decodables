# Admin 功能规格

> **版本**: 1.0.0
> **创建日期**: 2026-02-05
> **状态**: 🟡 待补充
> **同步范围**: [fullstack]
> **对应代码**: `api/routers/admin/`, `app/admin/`

---

## 概述

管理后台功能，面向运营和管理员。

---

## 功能模块

### 用户管理
- 用户列表查询
- 用户详情查看
- Tier 调整
- 积分赠送
- 账户状态管理

### 系统配置
- Tier 配置（价格/积分/权益）
- 积分配置（AI 成本）
- 系统配置（维护模式）

### 内容管理
- 官方素材管理
- 模板管理
- 分类管理

### 内容审核
- Marketplace 商品审核
- 用户举报处理

### 主题管理
- Daily Doodle 主题
- 活动管理

### 文章管理
- 新闻/公告发布
- 博客文章管理

### 营销管理
- 优惠码管理
- 促销活动

### 数据分析
- 业务指标看板
- 数据报表

### 运营管理
- 系统监控
- 定时任务
- 维护模式

---

## 权限控制

Admin 功能仅限 `role=admin` 用户访问。
