> **同步范围**: [fullstack]

> **最后更新**: 2026-02-05

## 一、概述

### 1.1 功能定位

素材市场提供丰富的教育素材资源，用户可以浏览、搜索和使用各类素材。

### 1.2 素材分类 (10 类)

| 分类 | 说明 |
|------|------|
| AI Generate | AI 生成工具 |
| Templates | 模板 |
| Characters | 人物角色 |
| Backgrounds | 背景图 |
| Objects | 物品元素 |
| Decorations | 装饰元素 |
| Icons | 图标 |
| Frames | 边框相框 |
| Text Effects | 文字效果 |
| Uploads | 用户上传 |

## 四、搜索筛选

---

## 五、收藏功能

### 5.1 添加收藏

点击素材上的 ♥ 按钮添加到收藏

### 5.2 收藏列表

在 "Favorites" 标签查看所有收藏的素材

### 5.3 取消收藏

再次点击 ♥ 或在收藏列表中移除

---

## 六、API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/marketplace/assets` | GET | 获取素材列表 |
| `/marketplace/categories` | GET | 获取分类 |
| `/marketplace/search` | GET | 搜索素材 |
| `/marketplace/favorites` | GET | 获取收藏 |
| `/marketplace/assets/{id}/favorite` | POST/DELETE | 收藏/取消 |
