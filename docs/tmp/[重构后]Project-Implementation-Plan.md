## 6. 风险与依赖

### 6.1 风险矩阵

| 风险 | 影响 | 可能性 | 缓解措施 |
|------|------|--------|----------|
| **画布架构复杂度** | 🔴 高 | 🟡 中 | 分阶段实施，保持现有功能稳定 |
| **Fabric.js 限制** | 🔴 高 | 🟡 中 | 抽象层隔离，预留 Konva 迁移路径 |
| **移动端性能** | 🟡 中 | 🟡 中 | 分层渲染，降级策略 |
| **Procreate 格式** | 🟢 低 | 🟡 中 | 建议用户导出为 PSD |
| **浏览器兼容性** | 🟡 中 | 🟢 低 | 测试矩阵，polyfill |
| **工时估算偏差** | 🟡 中 | 🟡 中 | 预留 20% buffer |
