## 1. 商业模式与定价策略 (Business Model)

鉴于 B2C 教育市场的支付习惯，采用 **“积分制 + 订阅制”** 混合模式。核心逻辑为 **“免费制作 (Free to Create) -> 满意付费下载 (Pay to Download)”**。

### 1.1 积分消耗规则 (Credit Rules)
* **启动项目 (Project Start):** **0 Credits** (所有用户均可免费启动)。
* **图片生成 (Initial Gen):** **0 Credits** (首次生成整书免费)。
* **图片重绘 (Regeneration):** **5 Credits /次** (无免费额度，每次AI重绘均需扣分)。
* **PDF 下载 (Download):** **50 Credits /本**。
    * **扣费时机**: 点击下载按钮时**立即扣除**。
    * **重下载规则**: 若项目**未进行任何修改**，再次下载不扣费；**一旦有任何编辑**（文字修改、图片重绘、素材替换），再次下载需**重新扣除 50 Credits**。
* **智能功能 (OCR/Stickers):** 包含在特定权益中，不额外单次扣费，但受订阅等级限制。

### 2.2 交互逻辑详解

#### 1. 初始上传与动态生成 (Initial Upload & Gen)
* **首次使用**: 页面卡片默认为空，中间显示 `[EDIT]` 按钮。
* **上传方式**: 用户点击卡片中心的 `EDIT` 按钮，直接进入**全屏编辑器**。在编辑器中，用户可以使用组件库中的 `Upload` 功能上传本地图片填充该页。
* **混合生成**: 用户手动编辑/上传了 P1, P2 后，返回主界面在底部输入 Topic 点击 "Generate 8 Pages"，系统将保留 P1, P2 (自动视为锁定状态)，并AI生成 P3-P8 的内容。

#### 2. 全屏编辑与素材库 (Full-Screen Edit & Media Lib)
* **入口**: 点击卡片上的 `EDIT` 按钮。
* **素材来源 (Media Library)**:
    * **Upload**: 支持现场上传本地图片。
    * **Current Session**: 显示本次会话中所有生成过的图片（含废弃的重绘图）。
    * **All History (Pro Only)**: Pro 用户可浏览并选择**过往所有项目**中生成的图片，实现跨项目素材复用。

#### 3. 锁定机制 (Lock Logic)
* **UI**: 卡片左上角的 `🔓` 图标。
* **行为**: 点击变为 `🔒`。手动上传图片的页面会自动默认为锁定状态。
* **逻辑**: 全局生成时跳过锁定页。

#### 4. 导出与严格扣费 (Export & Strict Deduction)
* **预览 (Preview)**: 点击 `PDF Review & Download` 弹出预览窗口。此时看到的图片**均带有大水印 (Watermarked)**。
* **下载流程 (Download Flow)**:
    1.  点击弹窗内的 `Confirm Download` 按钮。
    2.  **系统先执行扣费** (50 Credits)。
    3.  扣费成功后，去除水印，生成 PDF 和 ZIP 下载链接。
* **再编辑逻辑 (Re-edit Policy)**:
    * 用户下载后，若对项目进行了**任何编辑** (改字、换图、重绘)。
    * 再次点击下载时，**视为新版本**。
    * 系统提示 *"Changes detected. Deduct 50 Credits to download new version?"*，确认后**重新扣费**。

## 3. 技术架构 (Tech Stack)

| 模块 | 选型 | 理由 |
| :--- | :--- | :--- |
| **前端框架** | **Next.js 15** + Tailwind CSS | App Router 架构。 |
| **画布引擎** | **Fabric.js** | **[核心]** 渲染可视化编辑器，支持拖拽、缩放、图层管理。 |
| **状态管理** | **Zustand / React Context** | **[核心]** 管理 `selection` (选中页), `locks` (锁定状态), `context` (Global/Page) 的复杂状态切换。 |
| **后端 API** | **FastAPI (Python)** | 处理 AI 逻辑和复杂的 PDF 绘制。 |
| **安全/风控** | **Keyword Filter (Python)** | 处理 Prompt 敏感词过滤。 |
| **PDF 引擎** | **ReportLab** | 基于坐标 (`x, y, w, h`) 精确绘制。 |
| **数据库** | **Supabase** | 存储 User, Credits, Projects (JSON State), Assets。 |
| **AI 模型** | **GPT-4o-mini** (文本) / **Fal.ai** (绘图) | 成本低，速度快。 |

### 3.1 数据存储架构 (Data Storage Strategy)

为了支持**二次编辑**和**资源复用**，系统存储 **结构化元数据 (JSON State)**。

* **表结构设计 (Supabase)**:
    * **Table `projects`**:
        * `canvas_data` (JSONB): 存储 8 个页面的完整结构、锁定状态、素材引用。
        * `last_downloaded_hash`: 存储最后一次付费下载时的状态 Hash，用于判断是否发生修改。
    * **Table `assets`**:
        * 存储原始图片 URL，支持跨页面复用。

## 4. 本地化细节 (US Localization)

1.  **字体 (Fonts)**: 需集成 Dyslexia-friendly (阅读障碍友好) 字体，如 **OpenDyslexic** 和 **Lexend**。
2.  **措辞 (Wording)**:
    * `Script` -> `Story text`
    * `Zine` -> `Foldable Book` / `Mini-Book`
3.  **纸张**: 默认 **US Letter**。
4.  **内容安全**: Fal.ai Prompt 强制追加 `safe for work, children's book style`。
5.  **版权风控 (IP/Copyright Check)**:
    * **关键词黑名单**: 建立敏感 IP 词库 (如 "Disney", "Pokemon")。
    * **拦截逻辑**: 包含敏感词时，前端提示并拒绝生成。
